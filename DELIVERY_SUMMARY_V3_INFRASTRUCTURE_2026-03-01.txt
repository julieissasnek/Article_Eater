IMPLEMENTATION DETAILS
======================

Technology Stack
  - Python 3.10+
  - OpenAI Python client (2.24.0)
  - Standard library: json, pathlib, logging, time, argparse
  - Error handling: Automatic retry, exponential backoff, regex fallback

API Configuration
  - Model: gpt-4o (fastest and most accurate for structured extraction)
  - Temperature: 0.1 (deterministic, low variance)
  - Response Format: JSON mode (guaranteed valid JSON)
  - Max Tokens: 4000 (re-extraction), 2000 (surgical update)
  - Rate Limiting: 0.5s between calls (safe, allows ~7,200 calls/hour)

Data Flow
  Re-extraction:
    tier1_reextract.json 
      → load article manifest (59 articles)
      → for each: load extraction file (get metadata)
      → build v3 prompt (23,400 chars)
      → call OpenAI GPT-4o
      → parse JSON response
      → merge with original metadata
      → save updated extraction file
      → results summary to v3_reextraction_results.json

  Surgical Update:
    data/extractions/ (1,066 files)
      → find articles with n_findings > 0 (1,002 articles)
      → for each: load extraction file
      → build surgical prompt (2,700 chars)
      → call OpenAI GPT-4o
      → parse JSON response (v3 fields)
      → merge into original extraction (preserve findings)
      → save updated file
      → results summary to v3_surgical_update_results.json

SUCCESS METRICS (V3 Specification)
==================================

The v3 prompts define 8 success conditions:

SC-1: Direction Canonicalization
  - Target: 0% invalid direction values (only 4 canonical values)
  - Validation: JSON schema validation
  - Expected: 100% compliance

SC-2: Antecedent Specificity
  - Target: <10% vague antecedents (was 32% in v2)
  - Validation: Manual review of sample
  - Expected: 85-90% specific

SC-3: Sample Size Coverage (Empirical Only)
  - Target: >80% of empirical findings with sample_size (was 18% in v2)
  - Validation: Field count
  - Expected: 75-85% coverage

SC-4: Theory Linkage
  - Target: >50% of papers with theory_commitments (was ~20% in v2)
  - Validation: Count theory_commitments arrays
  - Expected: 50-60% of papers

SC-5: Mechanism Chains
  - Target: >60% of causal papers with mechanism_chain (was ~15% in v2)
  - Validation: Count mechanism_chain fields
  - Expected: 40-50% of causal papers

SC-6: Instrument Naming
  - Target: >70% of papers with instruments_used (was ~45% in v2)
  - Validation: grep for generic terms
  - Expected: 70-80% of empirical papers

SC-7: Schema Compliance
  - Target: 100% of JSON matches schema
  - Validation: JSON schema validator
  - Expected: 100% (enforced by response format)

SC-8: No Critical Nulls
  - Target: <1% of findings with critical nulls
  - Validation: Field count
  - Expected: 99%+ non-null on antecedent/consequent
