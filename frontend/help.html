💬 Frequently Asked Questions

🔧 Troubleshooting

⚠️ Search Not Returning Results

Possible causes:

  • Query is too specific or uses uncommon terms
  • Filters are too restrictive (check year range, paper type)
  • Semantic Scholar API may be temporarily unavailable

Solutions: Try broader search terms, remove filters, or check the status page.

❌ Processing Job Failed

Possible causes:

  • Paper PDF is corrupted or inaccessible
  • API quota exceeded
  • Text extraction failed (scanned images, non-standard format)

Solutions: Check the error message in Queue, verify API usage, or try manual upload of PDF.

💰 High API Costs

Optimization tips:

  • Enable caching to avoid reprocessing papers
  • Use preview mode before full processing
  • Filter papers by quality indicators (citation count, journal impact)
  • Process papers in batches during off-peak hours
