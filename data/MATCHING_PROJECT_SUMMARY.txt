MATCHING PIPELINE STRATEGY
================================================================================

The solution employed a cascading strategy:

1. DIRECT DOI MATCH (Zotero BibTeX)
   Query: Do the unmatched DOIs exist in BibTeX with existing PDF files?
   Result: 171 direct matches found and added

2. TITLE-BASED EXACT MATCH
   Query: For extraction DOIs with titles, find exact title matches in BibTeX PDFs
   Result: 11 matches via exact title normalization

3. TITLE-BASED FUZZY MATCHING
   Strategy: Similarity scoring (threshold: 75%) on normalized titles
   Result: 6 matches via fuzzy string matching

4. CROSSREF API LOOKUP (optional)
   Attempted to query CrossRef for titles of remaining unmatched DOIs
   Result: No additional matches via API (CDI not accessible or no results)
