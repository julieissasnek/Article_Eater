## WHAT THE PROJECT IS

Article Eater is a software system that helps experts evaluate scientific papers about architecture and human wellbeing. It uses a **web of belief** — a structured knowledge graph where higher-tier beliefs (theories, mechanisms) inform how lower-tier beliefs (individual findings) are evaluated. The system needs deep mechanistic knowledge about HOW architectural properties affect people, organized so an expert can rapidly locate relevant mechanisms when encountering a new finding.

**Three-tier structure:**
- **Tier 1**: Mechanistic templates (T1–T52, M1–M17, AX1–AX6) — formalized causal pathways
- **Tier 2**: Domain theories (ART, SRT, Biophilia) — reduced to Tier 1 mechanisms via formal ReductionClaim objects
- **Tier 3**: Individual findings from papers — evaluated against Tier 1/2 knowledge

**Unifying theoretical framework**: Predictive processing / prediction error (PE). The brain continuously generates predictions; architectural properties confirm or violate those predictions; the magnitude, valence, and resolution of PE determines cognitive and emotional response. vmPFC is the domain-general value computation node, confirmed across 6+ domains.
