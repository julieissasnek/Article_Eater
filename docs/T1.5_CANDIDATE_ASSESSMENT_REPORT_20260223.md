## DETAILED ANALYSIS

### CANDIDATE 1: Episodic Memory Theory (Tulving)

**Domain**: Memory systems; organization of autobiographical experience across time and context
**Original claim**: Humans have distinct episodic memory systems supporting retrieval of specific events with phenomenological "mental time travel"
**T1 Parent Framework(s)**: MS (Memory Systems)

#### Current Coverage
- **Templates covered**: 7 out of 208 (3.4%)
- **Templates identified**:
  1. ED_HIPPOCAMPAL_ENCODING_001 — hippocampal relational binding in environmental encoding
  2. ED_SCHEMA_ENCODING_001 — schema extraction from episodic traces
  3. ED_SYSTEMS_CONSOLIDATION_001 — systems consolidation of episodic to semantic memory
  4. ED_RECONSOLIDATION_001 — memory reconsolidation during environmental re-exposure
  5. THRESHOLD_EPISODIC_BOUNDARY_001 — event boundary detection in temporal experience
  6. BRECVEMA_MEMORY_005 — memory as component of brainstem-rooted emotional resonance
  7. SN_CONTEXT_MEMORY_002 — spatial navigation with memory for environmental context

#### Analysis

**What the theory organizes well**:
- Episodic memory as **distinct from semantic memory**: The ED (Episodic/Declarative) template cluster captures the hippocampal specificity for what-where-when binding. Tulving's core claim about the "autonoetic consciousness" aspect (re-experiencing past events) maps directly to CA1 relational binding mechanisms (ED_HIPPOCAMPAL_ENCODING_001).
- **Temporal structure of episodes**: THRESHOLD_EPISODIC_BOUNDARY_001 operationalizes the event segmentation that structures episodic experience.
- **Consolidation dynamics**: ED_SYSTEMS_CONSOLIDATION_001 captures the slow transformation of episodic traces into semantic generalizations — a central prediction of systems consolidation theory.

**Why coverage is inadequate**:
1. **Episodic memory is NOT the organizing principle of the system's architecture**. The 208 templates are organized around *mechanistic T1 processes* (predictive processing, spatial cognition, neuromodulation, multisensory integration) and their *domain applications* (visual, auditory, material, social). Episodic memory is one *consequence* of these mechanisms, not a primary organizing axis.

2. **Templates addressing episodic phenomena are distributed across multiple T1 frameworks**, not unified under Memory Systems:
   - BRECVEMA_MEMORY_005 (episodic component) is primarily under Predictive Processing (brainstem-rooted expectation) and Salience Network, not MS
   - SN_CONTEXT_MEMORY_002 (episodic context binding) is under Spatial Navigation (SN) first, MS second
   - ED_HIPPOCAMPAL_ENCODING_001 lists t1_frameworks: ["MS", "SN"] — indicating it sits at the intersection of two frameworks

3. **The theory lacks explanatory depth within the system's mechanistic vocabulary**. Tulving's theory describes *what* episodic memory is (autonoetic consciousness, mental time travel) but does not specify:
   - How prediction error magnitude modulates episodic encoding strength
   - Which neuromodulatory signals determine "distinctiveness" thresholds
   - Why some environmental episodes are memorable and others are forgotten (beyond generic novelty)
   - How pattern separation capacity in DG interacts with age, stress, or interoceptive state

4. **Irreducible residuals are substantial**:
   - **Why do some environments produce strong episodic memories while others fade?** Episodic Memory Theory says "distinctiveness," but the MS templates explain this through pattern separation thresholds, novelty detection (NM), and stress modulation (IC). The "distinctiveness → memory strength" link in Tulving is explained by the underlying mechanisms, not asserted as a theory.
   - **Why does episodic memory depend on context?** Tulving describes context effects; predictive processing explains them through generative model precision. The theory doesn't reduce further mechanistically.

#### Verdict: **RECOMMEND REJECT**

**Justification**: Episodic Memory Theory fails criterion #3 (≥60% template coverage) with catastrophic shortfall (-56.6 percentage points). More fundamentally, it fails criterion #4 (irreducible residuals). The theory's core claims are *explained by* T1 frameworks (Memory Systems, Spatial Navigation) rather than explaining them. The templates covering episodic phenomena are already embedded in MS, SN, and other frameworks; promoting Episodic Memory Theory to T1.5 would create redundant abstraction. The theory is valuable as a *phenomenological organizing schema* (Tier 2) but does not qualify as a T1.5 mechanistic domain-specific theory.

**Path forward**: Keep Episodic Memory Theory in Tier 2, where it serves as a conceptual organizing framework for memory phenomena. Deepen MS templates to explain episodic specificity (e.g., why CA1 vs. CA3 for episodes, what determines the "what-where-when" binding strength, how consolidation extracts semantic knowledge).

### CANDIDATE 2: Berlyne's Arousal Theory

**Domain**: Aesthetic preference; relationship between stimulus complexity and hedonic value
**Original claim**: Aesthetic preference follows an inverted-U function of stimulus complexity/novelty mediated by arousal
**T1 Parent Framework(s)**: NM (Neuromodulatory Systems) — or possibly PP (Predictive Processing)

#### Current Coverage
- **Templates covered**: 2 out of 208 (1.0%)
- **Templates identified**:
  1. PROCESSING_STYLE_MODULATION_001 — how arousal tunes analytic vs. intuitive processing
  2. CROSS_ENVIRONMENTAL_PROCESSING_STYLE_001 — same mechanism applied across domains

#### Analysis

**What the theory addresses**:
Berlyne's inverted-U (complexity/novelty → arousal → hedonic preference) is directly relevant to architectural preference. The Goldilocks principle in the T1.0 architecture document explicitly invokes Berlyne's framework:

> "Moderate prediction errors that are resolvable are rewarding (dopaminergic reward from successful model updating); prediction errors too large to resolve are aversive (noradrenergic hyperarousal); prediction errors too small are boring (insufficient dopaminergic activation)." — Section 3.5 of T1.0 document

This is a *reinterpretation* of Berlyne through Predictive Processing (PP) and Neuromodulation (NM).

**Why coverage is so inadequate**:
1. **The system has *already absorbed* Berlyne's theory into T1.1 (Predictive Processing)**. The inverted-U is now explained through the Goldilocks zone of prediction error, not as a separate arousal-mediated phenomenon. Templates involving complexity, novelty, or aesthetic preference (e.g., T1, T2, AX_DOSE_RESPONSE_007, NM_DOPAMINE_NOVELTY_002) reduce Berlyne's claims to prediction error dynamics.

2. **Berlyne_Arousal appears in only 2 templates as a t1_5_candidate**, and both are marginal:
   - PROCESSING_STYLE_MODULATION_001: This is about *how* arousal affects processing style (analytic vs. holistic), not about the complexity-preference relationship itself
   - CROSS_ENVIRONMENTAL_PROCESSING_STYLE_001: The cross-domain version of the same mechanism

3. **The theory does not organize new phenomena**. The system already has:
   - NM_DOPAMINE_NOVELTY_002 — dopaminergic response to novelty (part of NM framework)
   - NM_NORADRENERGIC_EXPLORE_006 — noradrenergic explore-exploit tradeoff (part of NM framework)
   - AX_DOSE_RESPONSE_007 — dose-response of environmental properties (already explains why more complexity isn't always better)
   - All complexity-related templates (T1, T2, visual fractal scaling, etc.) are organized under PP or NM, not Berlyne

4. **Irreducible residuals are missing**. The theory predicts that complexity-preference relationships are mediated by arousal, but:
   - The system explains arousal through neuromodulatory precision-weighting of prediction errors
   - The system explains preference through dopaminergic reward from successful prediction error reduction
   - Berlyne's "arousal" is a proxy for NM activation; the underlying mechanism is in T1

#### Verdict: **RECOMMEND REJECT**

**Justification**: Catastrophic shortfall in template coverage (1.0% vs. 60% threshold, -59 pp). More critically, Berlyne's theory is already *integrated into* the T1 frameworks (specifically Predictive Processing and Neuromodulatory Systems). The inverted-U relationship is explained through the Goldilocks principle of prediction error resolution. The two templates that cite Berlyne_Arousal as a t1_5_candidate are about *processing style modulation*, not about the complexity-preference relationship that is the core of Berlyne's theory. Promoting Berlyne to T1.5 would create a redundant theoretical layer below T1 despite being explained by T1.

**Path forward**: Keep Berlyne in Tier 2 as a phenomenological organizing schema for aesthetic preference. Deepen NM and PP templates to capture domain-specific arousal-complexity interactions (e.g., visual complexity, acoustic complexity, material complexity). Consider whether "collative variables" (novelty, complexity, surprise, incongruity) each have distinct neural implementations in different sensory modalities, which would justify T1.5 theories for each modality (Berlyne_Visual, Berlyne_Auditory, etc.), but only if supported by substantial template coverage.

### CANDIDATE 3: Predictive Coding of Music

**Domain**: Auditory processing and musical emotion; role of expectation violation in music experience
**Original claim**: Musical emotions arise from violations of tone/harmony/rhythm expectancies; magnitude and resolution of prediction errors drive affective response
**T1 Parent Framework(s)**: PP (Predictive Processing)

#### Current Coverage
- **Templates covered**: 2 out of 208 (1.0%)
- **Templates identified**:
  1. NEURAL_MUSIC_EMOTION_ARCH_001 — neural mechanisms of emotion in music perception
  2. BRECVEMA_EXPECTANCY_004 — brainstem-rooted expectation violation and emotional response

#### Analysis

**What the theory addresses**:
The predictive coding of music is a well-developed account (Koelsch, Huron, Salimpoor) that explains how musical structure (melody, harmony, rhythm) generates predictions in the auditory system, how violations of those predictions produce emotional responses, and how the resolution of violations is rewarding. This directly engages with T1.1 (Predictive Processing).

**Why coverage is inadequate**:
1. **Music is not a primary organizational domain in the Article Eater system**. The 208 templates are weighted heavily toward:
   - Visual/spatial domains (visual preference, spatial navigation, visual complexity)
   - Social/emotional domains (affect construction, social proximity, safety signaling)
   - Auditory domains exist (acoustic ecology, auditory scene analysis, reverberation) but are minority

2. **The two templates addressing music are not principally about predictive coding of music**:
   - NEURAL_MUSIC_EMOTION_ARCH_001: This is about general emotional architecture in music perception, not specifically about expectation violations or prediction error resolution
   - BRECVEMA_EXPECTANCY_004: This is about brainstem-rooted expectation in general (part of BRECVEMA framework), not specific to music

3. **Predictive coding already applies to non-musical domains**. The system has:
   - PP templates explaining prediction error in *visual* scenes (T1, T2, VF1, VF2, VF3)
   - PP templates explaining prediction error in *spatial* navigation (SPATIAL_INTEGRATION_PE_001)
   - PP templates explaining prediction error in *tactile* feedback (CT_AFFECTIVE_TOUCH_001 implicitly)

   Music is one instantiation of PP in the auditory domain, not a separate theoretical framework.

4. **Irreducible residuals are absent**. Predictive Coding of Music makes specific predictions about which harmonic violations are most emotionally salient (Huron's "ITPRA" model), but:
   - The system explains this through neuromodulatory precision-weighting (NM)
   - The system explains emotional salience through interoceptive inference (IC)
   - The musical component (harmonic structure, tonal grammar) is *cultural knowledge* (schema-based expectations), not a mechanistic framework

5. **The theory does not explain architectural/environmental effects uniquely**. Music's role in built environments is *ambient* (background music in spaces) or *event-based* (concerts, performances), not a constitutive feature of buildings. This makes it a secondary phenomenon, not a primary organizing domain for neuroarchitecture.

#### Verdict: **RECOMMEND REJECT**

**Justification**: Severe shortfall in coverage (1.0% vs. 60%, -59 pp). Music is addressed in the system, but Predictive Coding of Music is already incorporated into the Predictive Processing (T1.1) framework. The system explains musical emotion through PP + NM + IC, not through a separate T1.5 theory. The two templates that cite Predictive_Coding_Music are about expectation and emotional resonance in general, not music-specific predictive coding. Promoting this to T1.5 would fragment the unified PP framework without explaining phenomena that PP doesn't already cover.

**Path forward**: Treat music as one domain within which Predictive Processing operates. Develop more specific auditory templates that address music-environment interactions (e.g., background music complexity and attention allocation, rhythm synchrony with body movement, harmonic tuning and emotional state). These would remain under PP, not under a separate music theory.

### CANDIDATE 4: Auditory Scene Analysis (Bregman)

**Domain**: Auditory perception; how listeners segregate and organize simultaneous acoustic sources
**Original claim**: Auditory system groups acoustic elements into coherent "streams" using spectral, temporal, and spatial cues; limits on stream segregation capacity affect cognitive load and stress
**T1 Parent Framework(s)**: MSI (Multisensory Integration) — or possibly IC (Interoceptive Construction)

#### Current Coverage
- **Templates covered**: 3 out of 208 (1.4%)
- **Templates identified**:
  1. AUD_SCENE_ANALYSIS_001 — stream segregation complexity and cognitive load
  2. AUDITORY_FRACTAL_SCALING_001 — fractal properties of acoustic scenes and preference
  3. AUD_REVERBERATION_SPACE_003 — reverberation properties and stream coherence in spaces

#### Analysis

**What the theory addresses**:
Bregman's Auditory Scene Analysis is a foundational framework for understanding how listeners parse complex soundscapes. Critically, it has direct relevance to neuroarchitecture: open-plan offices, hospitals, and busy public spaces generate high acoustic complexity → stream segregation demands → cognitive load → stress. The AUD_SCENE_ANALYSIS_001 template explicitly references Bregman and models stream segregation capacity as a function of source number.

**Why coverage is still inadequate**:
1. **Auditory Scene Analysis is NOT the organizing principle for the acoustic/auditory domain**. The system organizes auditory phenomena around:
   - **Multisensory Integration (MSI)**: How auditory input is combined with visual, proprioceptive, and interoceptive signals (MSI_CONGRUENCY_PRINCIPLE_001, MSI_INVERSE_EFFECTIVENESS_002)
   - **Predictive Processing (PP)**: How auditory expectations are formed and violated (ACOUSTIC_EMOTION_MAPPING_001, NEURAL_MUSIC_EMOTION_ARCH_001)
   - **Neuromodulation (NM)**: How acoustic complexity modulates arousal and dopamine (implicitly in stress templates)

2. **Stream segregation is explained through PP + MSI, not as a separate mechanistic principle**:
   - Bregman's spectral/temporal/spatial grouping rules are learned patterns → generative model expectations
   - Violations of those patterns produce prediction errors → MSI conflict signals
   - High stream number exceeds processing capacity → precision-weighting (NM) mediated by locus coeruleus

3. **The three templates have different theoretical commitments**:
   - AUD_SCENE_ANALYSIS_001: Uses ASA as primary framework but also lists t1_frameworks: ["MSI", "PP"] — indicating it's *explained by* MSI and PP, not reduced to ASA
   - AUDITORY_FRACTAL_SCALING_001: About acoustic fractal properties, not stream segregation per se (maps to visual fractal work via analogy)
   - AUD_REVERBERATION_SPACE_003: About architectural acoustics (reverberation) affecting stream coherence, not ASA per se

4. **Critical gap: ASA does not explain *why* stream segregation capacity is limited**. Bregman observes that listeners can typically segregate 3-5 streams reliably, but the *mechanism* (working memory capacity, attentional bottleneck, cochlear processing limits) is outside ASA. The system explains this through:
   - **IC (Interoceptive Construction)**: Limited resources for body state inference leave fewer resources for acoustic analysis
   - **DT (Dual Process)**: Implicit stream segregation is fast but capacity-limited; explicit attention to streams is slow
   - **NM**: Noradrenergic precision-weighting determines which streams get allocated resources

5. **Irreducible residuals**: Bregman's theory predicts stream segregation success from acoustic features alone. But the system shows that:
   - Stress state (allostatic load, cortisol) reduces stream segregation (AX_CONTROL_STRESS_004)
   - Attention modulates segregation (listeners can focus on one speaker in a cocktail party)
   - Musical training enhances segregation capacity (expertise effect)

   These interactions are NOT explained by ASA but by NM + DT + expertise-dependent schema updating.

#### Verdict: **RECOMMEND DEFER** (with strong provisos)

**Justification**: While coverage is severely short (1.4% vs. 60%, -58.6 pp), Auditory Scene Analysis is the *strongest* of the four candidates because:

1. **It organizes a distinct sensory modality domain** (auditory) with domain-specific constraints (stream segregation capacity limits)
2. **The templates mapping it explicitly acknowledge parent T1 frameworks** (AUD_SCENE_ANALYSIS_001 lists ["MSI", "PP"]), showing Bregman is recognized as *explained by* T1, not as a replacement T1.5
3. **The architectural relevance is clear and testable** (acoustic complexity → cognitive load → stress/wellbeing)
4. **The theory has irreducible content**: Stream segregation *capacity limits* are facts about auditory system design that don't reduce to PP or MSI alone

**However**, deferring requires:
- **Adding 120+ auditory domain templates** to reach 60% coverage. This means developing:
  - Templates for sound localization and spatial separation in architectural acoustics
  - Templates for auditory masking and speech intelligibility as functions of background complexity
  - Templates for rhythm perception and synchrony (entrainment) in spaces
  - Templates for acoustic material properties (absorption, diffusion) and their perceptual effects
  - Templates for ventilation noise, mechanical systems, and their stress effects
  - Templates for sound privacy and enclosure/isolation effects

- **Establishing mechanistic links to parent frameworks**. Each new auditory template must show:
  - Which MSI conflict signals are activated (cross-modal incongruence)
  - Which PP prediction errors are generated (auditory expectation mismatches)
  - Which NM systems are engaged (LC-NE for arousal, dopamine for salience, serotonin for threat)

- **Clarifying the irreducible residual claim**. Is the core claim that "auditory systems have inherent stream segregation limits" (a neurobiological fact) or "architecture must accommodate those limits" (an engineering fact)? The former is in neuroscience (already in NM/MSI); the latter is architectural principle.

## CONCLUSION

None of the four T1.5 candidates meet the formal qualification criteria. The primary barrier is **template coverage shortfall** (1.0-3.4% vs. 60% threshold), but the deeper issue is **theoretical integration**: all four candidates' core claims are already explained by existing T1 frameworks.

The assessment suggests that the system's architecture is more complete than initially assumed — the gaps are not missing theories but rather **underdeveloped domains** within existing frameworks (particularly auditory processing). Future T1.5 candidates should emerge from **domain development** (adding many templates in a coherent area) rather than **theory promotion** (elevating existing concepts).

**Auditory Scene Analysis** is the most promising future T1.5 candidate if the auditory domain receives systematic expansion. The other three candidates should remain in Tier 2, where they serve as valuable phenomenological organizing schemas without claiming mechanistic priority.
