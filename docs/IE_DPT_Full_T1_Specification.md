# PART I: PRECISE T1 SPECIFICATION

## 1.1 Ontological Status: Superordinate Framework

IE-DPT is not coordinate with T1 theories 1–10. It is superordinate. The argument is as follows:

Every existing T1 theory in the Goldilocks system describes a mechanism that operates within the implicit processing channel. The authoritative T1 roster (10 frameworks):

- **PP (Predictive Processing)** describes prediction error computation, which is subpersonal.
- **SN (Spatial Navigation / Cognitive Mapping)** describes automatic wayfinding and spatial representation.
- **DP (Dual-Process Evaluation)** — IE-DPT is the expansion of this framework.
- **DT (DMN/TPN Dynamics)** describes automatic network switching for internal vs. external focus.
- **NM (Neuromodulatory Systems)** describes autonomic and neuroendocrine responses that are largely implicit.
- **IC (Interoceptive / Constructionist Affect)** describes body-budget prediction and affect construction, which is subpersonal.
- **MS (Memory Systems)** describes hippocampal-striatal encoding that operates below awareness.
- **EC (Embodied Cognition)** describes embodied simulation, which is pre-reflective.
- **CB (Chronobiological Regulation)** describes circadian and ultradian rhythms operating automatically.
- **MSI (Multisensory Integration)** describes cross-modal binding, which is automatic and pre-attentive.

Note: ART, SRT, Biophilia, Berlyne, Fractal Fluency, Prospect-Refuge are **T1.5 domain theories** that bridge these T1 frameworks to specific architectural phenomena — they are not T1 frameworks themselves.

IE-DPT specifies **the selection mechanism** that determines which of these implicit-level theories is operative in a given encounter, what stimulus ecology each operates over, and how its outputs are evaluated. The Goldilocks optimum predicted by any of the implicit-level theories is conditional on the activity frame. Without specifying the activity frame, the implicit theories generate predictions that are indeterminate between multiple possible values. IE-DPT resolves the indeterminacy.

This superordinate status is not merely organizational convenience. It reflects a genuine architectural feature of neural computation: the prefrontal cortex imposes top-down bias signals (via beta-frequency oscillatory coherence) that reconfigure sensory and association cortex processing. This reconfiguration is not more of the same processing at a different level of precision (as PP would claim); it involves a qualitatively different computational regime — working-memory-dependent, capacity-limited, metabolically expensive, and neurally dissociable from the processes it controls.

## 1.2 Scope

IE-DPT applies to adult human experience of built and natural environments. It specifies how explicit cognitive processes (Type 2: goal-directed, working-memory-dependent, deliberate) configure, modulate, override, and evaluate the outputs of implicit processes (Type 1: automatic, associative, embodied, fast) in environmental response.

The theory covers:
- **Activity frame selection**: How the person's current goal determines the effective stimulus ecology
- **Aesthetic judgment**: How explicit evaluative frameworks modulate implicit hedonic responses
- **Metacognitive override**: How deliberate reasoning overrides or sustains implicit approach/avoidance
- **Expertise effects**: How accumulated explicit training sediments into altered implicit processing
- **Memory-mediated environmental meaning**: How explicit episodic memories and implicit associative learning jointly shape environmental response
- **Conflict between channels**: What happens when implicit and explicit assessments diverge

## 1.3 Core Claims

### C1: Superordinate Status
All existing T1 theories describe processes operating within the implicit channel. IE-DPT specifies the boundary conditions under which each operates. No T1-level prediction can be finalized without specifying the activity frame.

### C2: Activity-Relative Optimum
The Goldilocks optimum for any environmental variable (complexity, coherence, mystery, fascination, prospect, refuge, naturalness, multisensory congruence, etc.) is a function of the activity frame. Formally: **G_opt(V) = f(V, A)**, where V is the environmental variable, A is the activity frame, and f is a function that must be empirically determined for each V–A pair. The claim is that f is not constant in A — the optimum shifts.

### C3: Dynamic Cybernetic Loop
Implicit and explicit processing operate in a continuous loop:

**Phase 1 — Implicit initial assessment** (~0–300ms): Sensory processing, affective valence, gist extraction, embodied simulation, prediction error computation. This generates an initial response profile R₁.

**Phase 2 — Salience evaluation** (~150–500ms): The salience network (anterior insula + dACC) evaluates whether R₁ warrants explicit engagement, based on novelty, conflict detection, threat, goal-relevance, or voluntary initiative. This produces a binary gate signal: engage/do not engage.

**Phase 3 — Expected Value of Control computation** (~300–800ms): If the gate opens, the ACC/dACC computes whether the anticipated benefit of explicit engagement exceeds its cost (metabolic, temporal, opportunity). This is the EVC computation (Shenhav, Botvinick, & Cohen, 2013). EVC > threshold → explicit engagement proceeds.

**Phase 4 — Activity frame selection and deployment** (~500ms–2s): Anterior LPFC (BA 10, 46/9) represents the superordinate goal. The hierarchical control cascade (Badre) translates this into concrete processing configuration. PFC generates beta-frequency bias signals (Miller) that constrain posterior processing.

**Phase 5 — Implicit processing ecology reconfiguration** (~1–3s): The new top-down configuration alters which features are perceptually salient, which associations are activated, which predictions are generated, which embodied simulations are foregrounded. The effective stimulus changes. This is the epistemic bubble (Kirsh).

**Phase 6 — New implicit assessment** (ongoing): The reconfigured implicit system generates R₂, which may differ substantially from R₁. R₂ may trigger further salience evaluation (return to Phase 2), or the system may settle into a stable loop.

### C4: Dual-Sense Reconciliation
The theory operates with two senses of "implicit/explicit" that cross-classify:

**Kirsh-sense (representational)**: Information is explicit to the degree that it can be recovered without costly computation. It is implicit to the degree that recovery requires substantial computational work. This is a *continuum* defined over representations.

**Kahneman-sense (processing mode)**: Type 1 processing is automatic, fast, does not require working memory. Type 2 processing is deliberate, slow, requires working memory for hypothetical reasoning. This is a *bimodal distribution* defined over processes.

**Cross-classification produces four cells:**

| | Kahneman-Type 1 (automatic) | Kahneman-Type 2 (deliberate) |
|---|---|---|
| **Kirsh-explicit (cheap to extract)** | Cell A: Well-organized workspace enabling skilled performance. Chef's mise-en-place. Expert in a well-designed cockpit. The environment makes information cheap to extract AND the person processes it automatically. **This is the design ideal.** | Cell B: Well-organized workspace being deliberately analyzed. A designer evaluating a layout. Information is cheap to extract but the person is deliberately attending to it. **This is the evaluative/aesthetic mode.** |
| **Kirsh-implicit (costly to extract)** | Cell C: Automatic processing in a poorly organized space. Habituated occupant in a cluttered office — processing is automatic but informtion extraction is effortful, producing subtle autonomic stress signatures. **This is the habituation-masked suboptimality.** | Cell D: Deliberate processing in a challenging space. Student struggling with complex material in a disorienting library. Both the information and the processing are effortful. **This is cognitive overload territory.** |

**Architectural consequence**: Good design moves environments from Cell D → Cell A: making information cheap to extract (Kirsh-explicit) so that processing can be automatic (Kahneman-Type 1). But different activity frames define "which information" should be cheap to extract — hence the activity-relativity of design quality.

### C5: Sedimentation
Repeated explicit engagement reshapes implicit processing. What was once deliberate becomes automatic. This operates through:
- **Cortical reorganization**: Expanded representations for practiced stimulus categories (structural MRI evidence for expertise-related cortical thickness changes)
- **Striatal chunking**: Explicit action sequences consolidated into implicit motor/cognitive habits via cortico-striatal loops
- **Hippocampal-to-neocortical transfer**: Episodic memories generalized into semantic knowledge and implicit associative networks
- **Altered prediction machinery**: The generative model used for PE computation is itself a product of prior explicit engagement

**Architectural consequence**: An architect's implicit response to a building is not the same as a layperson's, because the architect's perceptual system has been reshaped by years of explicit training. No "universal" implicit response exists independent of expertise history.

### C6: Cost-Gated Engagement
Explicit processing is metabolically expensive (glucose consumption, cortisol load) and capacity-limited (4±1 items in working memory). It is not continuously active. It is deployed when the Expected Value of Control exceeds a threshold:

**EVC = Σ (P(outcome_i | control) × V(outcome_i)) − C(control)**

where P is the probability of each outcome given control deployment, V is its value, and C is the cost of control. The threshold is modulated by: current stress level (stress raises threshold → less explicit engagement), fatigue, motivation, individual differences in need for cognition, and the nature of the environmental encounter.

### C7: Conflict Detection and Measurability
When implicit and explicit assessments diverge, the ACC detects the conflict. This conflict generates measurable signatures: increased dACC BOLD, error-related negativity (ERN/N2 EEG component), elevated skin conductance, increased response latency, decreased confidence. Convergence between channels produces fluency, positive affect, rapid responding, and the phenomenological experience of "fit" between person and environment.

### C8: Memory Systems
Environmental response is jointly shaped by two memory systems:
- **Hippocampal (explicit)**: Context-specific episodic memories of past environmental encounters. Consciously accessible. "The last hospital I entered was where I received bad news."
- **Striatal (implicit)**: Statistical regularities learned through reinforcement. Not consciously accessible. "Spaces with this lighting/material/proportion profile have been associated with threat/reward."
- **Cross-talk**: Hippocampal memories generalize via pattern completion to influence striatal associations; striatal reward signals modulate hippocampal encoding priority.
- **Dopaminergic modulation**: Dopamine gates which system dominates. High DA → hippocampal/model-based dominance. Low DA → striatal/habitual dominance. The environment itself modulates DA (novelty, reward anticipation), creating a recursive loop.

## 1.4 Boundary Conditions

1. **Developmental**: Theory applies to adults with mature PFC. Children under ~12 have immature prefrontal cortex and show reduced explicit modulation of implicit response. Infant environmental responses are predominantly implicit.

2. **Neurological**: Theory presupposes intact PFC. Patients with frontal damage, neurodegenerative disease affecting PFC, or acute stress (which degrades PFC function via cortisol-mediated synaptic disruption) show reduced explicit modulation. This is not a failure of the theory but a testable prediction: PFC-compromised populations should show responses closer to what the implicit-only theories predict.

3. **Pharmacological**: Substances that impair working memory (alcohol, benzodiazepines, high-dose THC) reduce explicit modulation. Substances that enhance dopaminergic function (stimulants) may shift the balance toward explicit/model-based processing.

4. **Not a replacement**: IE-DPT does not replace the implicit-level theories. It specifies their operating conditions. PP, Berlyne, ART, SRT, etc. remain the correct mechanistic accounts of what happens within the implicit channel. IE-DPT tells you *which* implicit channel is operative and *what* it is operating over.

# PART II: T2 MECHANISMS — NEURAL SUBSTRATES

## 2.1 Primary Mechanisms

### M1: Prefrontal Top-Down Bias (Miller & Cohen, 2001)

**Neural substrate**: Dorsolateral PFC (BA 9/46), ventrolateral PFC (BA 44/45/47), anterior PFC (BA 10)

**Mechanism**: PFC neurons maintain patterns of activity representing current goals, rules, and task demands. These representations generate bias signals that propagate to posterior and subcortical structures via long-range axonal projections. The bias signals amplify task-relevant neural populations and suppress task-irrelevant ones.

**Oscillatory implementation**: Top-down control is carried by alpha/beta frequency oscillations (15–35 Hz). Beta oscillations originating in PFC constrain gamma-frequency (35–60 Hz) sensory processing in posterior cortex. When a new activity frame is selected, the beta pattern reconfigures, producing a new constraint landscape over sensory processing within 100–300ms.

**Mixed selectivity**: PFC neurons are not dedicated to specific tasks. The same neurons participate in multiple goal representations at different times, with the specific pattern encoding the current goal. This gives PFC extraordinary flexibility: it can configure the same downstream processing machinery in radically different ways.

**Measurement**: EEG (frontal beta power, beta-gamma coupling), MEG (directed information flow from frontal to posterior), fMRI (PFC BOLD, PFC-posterior functional connectivity), TMS (disruption of PFC → impaired top-down control).

**Architectural relevance**: This is the neural mechanism by which the activity frame reconfigures the perceptual ecology. When an architect shifts from casual viewing to formal evaluation of a space, frontal beta oscillations reconfigure posterior visual processing within hundreds of milliseconds, changing which features are amplified.

### M2: Hierarchical Control Cascade (Badre, 2008; Badre & Nee, 2018)

**Neural substrate**: Rostro-caudal gradient within lateral PFC:
- **Frontopolar cortex (BA 10)**: Most abstract, temporally extended goals. "I am evaluating this building as a healthcare design consultant."
- **Anterior LPFC (BA 46/9)**: Contextual rules and subgoals. "Right now I am assessing the wayfinding system."
- **Mid-LPFC (BA 44/45)**: Feature-level selection. "Attend to signage visibility and corridor legibility."
- **Posterior LPFC / Premotor (BA 6/8)**: Concrete action selection. "Look at the sign at that junction; evaluate its readability."

**Mechanism**: Each level constrains the level below it. Abstract goals cascade into concrete processing configurations. The cascade is implemented through oscillatory coupling: each hierarchical level imposes beta-frequency constraints on the level below.

**Measurement**: fMRI (rostro-caudal gradient of activation as function of control demand abstraction), TMS (level-specific disruption).

**Architectural relevance**: Activity selection resides at the apex (BA 10). A single superordinate goal change at the top of the hierarchy propagates through all levels, reconfiguring everything from which perceptual features are attended to which motor programs (e.g., where to look, how to move) are selected.

### M3: Salience Network Switching (Menon & Uddin, 2010; Uddin, 2015)

**Neural substrate**: Anterior insula (AI) + dorsal ACC (dACC), with projections to both CEN and DMN.

**Mechanism**: The salience network detects behaviorally relevant events (novelty, threat, reward, goal-relevance) and initiates switching between:
- **Default Mode Network (DMN)**: Medial PFC, posterior cingulate, angular gyrus. Internally directed: self-reference, episodic retrieval, future simulation, mind-wandering.
- **Central Executive Network (CEN)**: Dorsolateral PFC, posterior parietal cortex. Externally directed: goal-structured, task-focused, working-memory-dependent.

The AI functions as a causal hub: when a salient environmental event is detected, the AI triggers CEN engagement and DMN suppression (for external task focus) or DMN engagement and CEN suppression (for internal processing like episodic retrieval or self-relevant evaluation).

**Insula subdivisions**: 
- Dorsal anterior insula: Cognitive/attentional salience
- Ventral anterior insula: Affective/interoceptive salience
This subdivision maps onto the representational (Kirsh) vs. processing (Kahneman) distinction: dorsal AI detects salience in the task-relevant sense; ventral AI detects salience in the body-state/affective sense.

**Measurement**: fMRI (SN activation, dynamic functional connectivity between SN/CEN/DMN), EEG (P3a component as salience detection marker), pupillometry (pupil dilation as salience proxy).

**Architectural relevance**: Entering a new space triggers salience detection. The AI evaluates the environmental change and determines whether to engage CEN (deliberate processing of the new space) or allow DMN continuation (continuing internal thought, treating the space as background). The speed and efficiency of this switching is an individual difference variable that should moderate architectural response.

### M4: Expected Value of Control (Shenhav, Botvinick, & Cohen, 2013)

**Neural substrate**: dACC (dorsal anterior cingulate cortex), with inputs from OFC (value), LPFC (control signals), and insula (salience).

**Mechanism**: The dACC computes a cost-benefit analysis for deploying cognitive control. Inputs: (a) anticipated benefit of control (how much better will the outcome be if I engage explicitly?), (b) anticipated cost (metabolic expense, time, opportunity cost), (c) current control state (how much control is already deployed?). Output: a signal that either intensifies or reduces LPFC engagement.

**Measurement**: fMRI (parametric modulation of dACC BOLD by EVC), pupillometry (pupil dilation tracks EVC), task-evoked autonomic responses (HR deceleration at control engagement).

**Architectural relevance**: Most environmental encounters do not trigger explicit engagement — people walk through buildings on autopilot. The EVC mechanism determines *when* the bridge from implicit to explicit is traversed. Novelty, discrepancy from expectation, personal relevance, task demand, and social context all raise EVC. Fatigue, stress, habituation, and low stakes lower it. This means the same space can trigger explicit engagement or not, depending on contextual EVC factors.

### M5: Conflict Detection (De Neys, 2012; De Neys, Vartanian, & Goel, 2008)

**Neural substrate**: dACC (conflict monitoring), reflected in ERN/N2 EEG components, with downstream effects on autonomic arousal (SCR).

**Mechanism**: When Type 1 and Type 2 produce divergent assessments, the dACC registers the conflict. Critically, this detection occurs *even when the person gives the biased (Type 1) response* — the brain detects the conflict before (or without) the person consciously noticing it. This generates a constellation of measurable signals: increased dACC activation, elevated skin conductance, increased response latency, decreased confidence ratings.

**Debate**: De Neys argues conflict detection is itself Type 1 (automatic, intuitive sensitivity to logical structure). Thompson and others argue it requires minimal Type 2 engagement. Both positions agree the conflict is detectable and generates measurable signatures; the disagreement is about the detection mechanism's processing type.

**Architectural relevance**: When someone enters a space and has an immediate negative affective response (Type 1: "this feels wrong") but also has explicit knowledge that the space should be fine (Type 2: "this was recently renovated, it meets all standards"), the ACC registers the conflict. This conflict state is the measurable neural signature of implicit/explicit divergence in environmental response.

### M6: Dual Memory Systems (Shohamy & Wagner, 2008; Foerde & Shohamy, 2011)

**Neural substrate**: Hippocampus (explicit episodic memory) + Striatum (implicit associative/habit learning) + Dopaminergic midbrain (VTA/SNc, modulating both systems).

**Mechanism**: Environmental response is simultaneously shaped by:
1. **Hippocampal system**: Consciously accessible episodic memories of specific past encounters with similar environments. Context-dependent, one-shot learning capable, flexible retrieval.
2. **Striatal system**: Gradually learned statistical associations between environmental features and reward/threat outcomes. Not consciously accessible. Driven by dopaminergic reward prediction errors.
3. **Cross-talk**: Hippocampal representations influence striatal decision-making via vmPFC integration. Striatal reward signals modulate hippocampal encoding, determining which experiences are prioritized for consolidation.

**Dopaminergic modulation**: High dopamine states (novelty, reward anticipation, stimulant use) favor hippocampal encoding and model-based (explicit) reasoning. Low dopamine states (familiar environments, anhedonia, fatigue) favor striatal dominance and habitual (implicit) responding.

**Architectural relevance**: The same space activates both systems simultaneously. A hospital corridor activates hippocampal episodic memories ("the last time I was here…") and striatal associations (implicitly learned correlations between spatial features and outcomes). The relative weight of these systems determines the response profile and is modulated by dopaminergic state — which is itself influenced by the environment (novel environments boost DA), creating a recursive loop.

### M7: Embodied Simulation Modulation (Gallese, 2005)

**Neural substrate**: Motor cortex, premotor cortex, somatosensory cortex (mirror neuron system broadly construed), modulated by PFC top-down signals.

**Mechanism**: Perceiving spaces and objects activates motor and somatosensory representations that simulate interaction with them. Seeing a staircase activates motor cortex for ascending; seeing a narrow passage activates body-schema compression representations. This simulation is automatic (Type 1) but its *content* is modulated by the activity frame (Type 2). When you think about a space as a user, you simulate your own movement. When you think about it as a designer, you simulate the movements of hypothetical users.

**Measurement**: fMRI (motor cortex activation during passive viewing), EMG (subliminal muscle activation), TMS (motor evoked potentials during spatial viewing).

**Architectural relevance**: Embodied simulation is the pre-reflective "feel" of a space — the visceral sense of openness, compression, invitation, threat. This is the deepest implicit layer. But it is not fixed: it is modulated by perspective (self vs. other), expertise (dancer vs. non-dancer), body state (healthy vs. injured), and activity frame. The explicit channel selects *which* embodied simulation is foregrounded.

### M8: Aesthetic Judgment Network (Chatterjee, 2014; Vessel, Starr, & Rubin, 2012)

**Neural substrate**: Three dissociable components:
1. **Perceptual processing** (occipital/parietal): Formal properties — symmetry, proportion, contour, fractal dimension. Largely Type 1.
2. **Hedonic valence** (medial OFC, ventral striatum, amygdala): Pleasure/displeasure, approach/avoidance. Largely Type 1.
3. **Aesthetic judgment** (dlPFC, dmPFC, default mode network for self-relevant evaluation): The deliberate evaluative act. Clearly Type 2.

**Mechanism**: These three components are dissociable. You can have perceptual fluency + positive hedonic valence + negative aesthetic judgment (deconstructivist architecture appreciated intellectually but perceptually challenging). Or positive hedonic valence + negative aesthetic judgment ("it's pretty but derivative"). The aesthetic judgment component recruits working memory and cultural/educational frameworks that are explicitly maintained.

**Measurement**: fMRI (triple dissociation of component activations), EEG (late positive potential as index of aesthetic evaluation, distinct from early perceptual components), behavioral (dissociation between fluency measures and evaluative ratings).

**Architectural relevance**: This is the neural basis of the McMansion effect, the placebo architecture effect, and the expertise-modulated aesthetic divergence. No purely implicit theory can explain why the same perceptual fluency produces different evaluations depending on the person's aesthetic framework.

# PART III: ARCHITECTURAL CONSEQUENCES

## 3.1 Primary Consequences (direct derivations from core claims)

### AC1: Same Room, Different Optima
**Derivation from C2 (Activity-Relative Optimum)**: The Goldilocks optimum for visual complexity in a hospital corridor is different for a patient (activity: recover, rest → lower optimal complexity), a nurse (activity: efficiently navigate and monitor → moderate optimal complexity with high legibility), and a visiting architect (activity: evaluate design → higher optimal complexity acceptable, even desired). No single complexity level can simultaneously optimize for all activity frames.

**Design implication**: Multi-use spaces require either (a) environmental variability (zones of different complexity) or (b) adaptable features (adjustable lighting, movable partitions) that allow the space to be reconfigured for different activity frames.

### AC2: Expertise Invalidates "Universal" Design Rules
**Derivation from C5 (Sedimentation)**: An architect's implicit response to a building is systematically different from a layperson's because years of explicit training have reshaped the architect's perceptual system. Rules like "people prefer moderate complexity" or "symmetry is universally pleasing" are not universal — they are expertise-relative. The design research literature is contaminated by this confound: studies using design professionals as participants produce different results from studies using naïve participants.

**Design implication**: Design guidelines must specify the target population's expertise level. What works for design-literate clients may not work for naïve occupants, and vice versa.

### AC3: The Habituation-Reengagement Cycle
**Derivation from C3 (Dynamic Loop) + C6 (Cost-Gated Engagement)**: Over time, occupants habituate to their environment. Implicit processing becomes maximally efficient and the environment becomes "invisible" (Phase 1 only, no salience trigger). But periodic reengagement can occur when: (a) something changes in the environment, (b) social input triggers re-seeing ("your apartment has amazing light"), (c) the occupant's activity frame changes (hosting guests → evaluating the space through their eyes), or (d) mood/stress shifts lower the EVC threshold.

**Design implication**: Environments that support long-term wellbeing need features that periodically reawaken explicit engagement — subtle seasonal changes, dynamic elements (light, vegetation, water), or design features that reveal new layers over time. Static environments produce complete habituation and lose their capacity to produce positive explicit engagement.

### AC4: Semantic Override of Physical Properties
**Derivation from C1 (Superordinate Status) + C8 (Memory Systems)**: A physically identical space can produce opposite responses depending on semantic content. A beautiful corporate lobby experienced by a climate activist who knows the company profits from fossil fuels; a spacious, well-lit hospital corridor experienced by a patient who received a terminal diagnosis in a similar corridor. The semantic content (explicit, hippocampal) overrides the physical properties (implicit, perceptual).

**Design implication**: Physical design is necessary but not sufficient for positive environmental response. Meaning, association, and narrative matter. Environmental branding, signage, communication of purpose, and cultural context are not superficial additions to "real" design — they are constitutive of the environmental response because they shape the explicit channel.

### AC5: The Persistence Paradox
**Derivation from C3 (Dynamic Loop, Phase 3 vs. Phase 1)**: People routinely persist in environments that their implicit systems assess as suboptimal — noisy cafés, uncomfortable libraries, challenging studios. This is Type 2 override of Type 1 approach/avoidance. The explicit assessment ("this environment serves my goals despite its discomfort") overrides the implicit assessment ("leave"). The override is metabolically costly and cannot be sustained indefinitely.

**Design implication**: Environments that require sustained explicit override for occupancy are fatiguing. The better design strategy is to align implicit and explicit channels — making environments that are both instrumentally effective (satisfying the explicit activity frame) and implicitly supportive (low stress, comfortable, well-organized). When alignment is impossible (some clinical, industrial, or educational environments require discomfort), providing recovery opportunities becomes essential.

## 3.2 Interaction Effects

### IX1: Activity × Complexity Interaction
**Mechanism**: Activity frame determines which features are processed (M1, M2). Different feature sets have different effective complexity. A visually rich space is effectively simpler for a person in a focused work activity frame (many features are suppressed by attentional filtering) than for a person in an exploratory activity frame (all features are attended to).

**Prediction**: The slope of the Berlyne inverted-U curve is steeper for focused activities (narrow tolerance band for complexity) and shallower for exploratory activities (wider tolerance band). The peak shifts rightward (toward higher complexity) for exploration and leftward for focused work.

**Interaction form**: Ordinal or crossover, depending on the complexity range. At moderate complexity, focused workers perform better than explorers (the complexity is within their narrower band). At high complexity, explorers perform better than focused workers (complexity exceeds the focused worker's band but remains within the explorer's).

### IX2: Expertise × Aesthetic Features Interaction
**Mechanism**: Sedimentation (C5) means experts and novices extract different features from the same stimulus. Experts attend to structural relationships (proportion, rhythm, spatial syntax); novices attend to surface features (color, material finish, size). The Goldilocks optimum for structural features differs from that for surface features.

**Prediction**: Experts and novices show divergent preferences for the *same* design features. A building with exquisite proportions but austere materials: experts rate highly, novices rate poorly. A building with mediocre proportions but rich surface finishes: novices rate highly, experts rate poorly.

**Effect size estimate**: Expert/novice divergence in evaluative ratings: d ≈ 0.6–1.0 based on analogous findings in music and visual art expertise studies.

### IX3: Stress × Explicit Override Interaction
**Mechanism**: Acute stress impairs PFC function via cortisol-mediated synaptic disruption (Arnsten, 2009). This degrades Type 2 processing capacity, reducing the ability to override implicit responses.

**Prediction**: Under low stress, explicit knowledge can effectively modulate implicit environmental response (e.g., knowing a building is safe overrides anxiety from the space's visual properties). Under high stress, implicit responses dominate and explicit override fails — the person responds primarily to the physical properties of the space regardless of their knowledge about it.

**Interaction form**: Crossover. The same person who successfully overrides implicit anxiety about a space under low stress may fail to do so under high stress. The space's physical design properties become more powerful determinants of response as stress increases.

**Architectural consequence**: Spaces designed for high-stress populations (emergency departments, crisis centers, homeless shelters) *cannot rely on explicit framing* to produce positive responses. They must be designed to produce positive implicit responses directly — via the existing T1 frameworks (biophilic elements, restorative features, low complexity, warm materials) — because the explicit channel is degraded.

### IX4: Dopamine State × Memory System Interaction
**Mechanism**: High dopamine states favor hippocampal/model-based processing; low dopamine states favor striatal/habitual processing (M6). The dopamine state is influenced by novelty (new environments boost DA), reward anticipation, circadian rhythm, and pharmacology.

**Prediction**: In novel environments (high DA), environmental response is dominated by explicit episodic associations and deliberate evaluation. In familiar environments (low DA), response is dominated by habituated implicit associations. The transition from novel to familiar tracks dopaminergic adaptation.

**Architectural consequence**: First impressions of a building are disproportionately shaped by explicit/episodic processing (high DA from novelty). Long-term occupancy is disproportionately shaped by implicit/habitual processing (low DA from familiarity). Design features that matter at first encounter (dramatic entrance, narrative signage, architectural "statement") may differ from features that matter for long-term occupancy (material durability, spatial flow efficiency, acoustic comfort). Both matter, but for different reasons operating through different neural systems.

### IX5: Activity Frame × Prediction Error Interaction
**Mechanism**: Activity frame determines the active generative model (C2, M1, M2), which determines what counts as a prediction error. The same physical feature is PE-generating under one frame and PE-confirming under another.

**Prediction**: A bold, unexpected architectural feature (e.g., a cantilevered volume over a courtyard) generates high PE for a patient seeking calm (violation of expected regularity) but low PE for an architecture student seeking novelty (confirmation of expected innovation). The PE magnitude for the same physical feature varies as a function of activity frame.

**Interaction form**: Crossover. Same feature → high PE under Frame A, low PE under Frame B. This means PP-based predictions of affective response (PE drives hedonic response via Schmidhuber/Berlyne mechanisms) are systematically modulated by activity frame.

**Architectural consequence**: "Surprise" in architecture is not a property of the building; it is a property of the building-in-relation-to-the-observer's-activity-frame. A design intended to delight can distress if the activity frame changes.

### IX6: Conflict × Decision Time Interaction
**Mechanism**: When implicit and explicit channels diverge (C7, M5), response time increases, confidence decreases, and ACC activates. The magnitude of this effect is proportional to the degree of divergence and modulated by individual differences in cognitive style.

**Prediction**: Environmental evaluations take longer and show more variability when the space produces conflicting implicit/explicit signals. A perceptually pleasant but semantically negative space (beautiful but morally compromised) or a perceptually harsh but semantically positive space (ugly but beloved institution) produce slower, less confident, more variable evaluations than spaces where channels align.

**Architectural consequence**: Post-occupancy evaluations that rely on self-report ratings are systematically biased by channel alignment. Spaces that produce aligned responses (implicit positive + explicit positive) receive higher, more confident ratings. Spaces that produce misaligned responses receive moderate ratings with high variance — not because the space is "average" but because respondents are averaging across conflicting signals. Researchers should measure implicit (autonomic, eye-tracking) and explicit (rating, verbal report) channels separately.

### IX7: Social Context × Activity Frame Interaction
**Mechanism**: The presence and behavior of other people in a space modulates both the implicit channel (social facilitation/inhibition, mirror neuron activation, contagion of affect) and the explicit channel (social norms constrain which activity frames are "appropriate," public self-consciousness modifies evaluation criteria).

**Prediction**: The same space produces different responses when occupied versus empty, and the direction of the difference depends on the social context. A library full of focused workers: enhances focused work activity frame (social facilitation, norm reinforcement). The same library full of chatting socializers: disrupts focused work frame, may trigger frame-switching to social activity.

**Architectural consequence**: Designing for occupancy means designing for social signaling. The space must cue appropriate activity frames not just through physical properties but through social affordances (seating arrangements that signal collaboration vs. solitude, acoustic zones that signal quiet vs. active).

### IX8: Circadian × Explicit Capacity Interaction
**Mechanism**: PFC function and working memory capacity vary with circadian rhythm, fatigue, and sleep quality. Type 2 processing is resource-limited and degrades under fatigue.

**Prediction**: The same person in the same space shows different implicit/explicit balance across the day. Morning (high WM capacity): more explicit modulation, stronger aesthetic judgment, more effective activity frame maintenance. Evening/fatigued (low WM capacity): more implicit dominance, less effective override of approach/avoidance, preferences shifting toward comfort and simplicity.

**Architectural consequence**: Spaces used across the day (offices, hospitals, homes) should provide environmental support for both states — zones of higher stimulation for morning/alert explicit engagement, and zones of lower stimulation for evening/fatigued implicit-dominant states. Fixed-stimulation environments are suboptimal across the circadian cycle.

### IX9: Trauma History × Environmental Features Interaction
**Mechanism**: Trauma produces hyper-conditioned implicit associations (amygdala-driven, resistant to extinction). Explicit knowledge ("I am safe") attempts to modulate these via PFC-mediated regulation, but the strength of the amygdala response may overwhelm PFC capacity.

**Prediction**: For individuals with environmental trauma (PTSD related to specific spaces — hospitals, combat zones, domestic settings), spaces with physical features resembling the trauma context produce implicit threat responses that cannot be fully overridden by explicit safety knowledge. The degree of override failure correlates with PFC integrity, current stress load, and time since trauma.

**Architectural consequence**: Trauma-informed design must prioritize avoiding implicit trauma triggers (specific acoustic properties, lighting conditions, spatial configurations associated with trauma) rather than relying on explicit reassurance (signage saying "you are safe"). The implicit channel cannot be argued with; it can only be avoided or gradually extinguished through repeated safe exposure.

### IX10: Cultural Knowledge × Perceptual Processing Interaction
**Mechanism**: Cultural knowledge (explicit, learned, stored as semantic memory) shapes the interpretive framework applied to spatial features. The same arched form reads as "sacred" in one cultural context, "classical" in another, "ornamental excess" in a third.

**Prediction**: Cross-cultural differences in architectural evaluation are not primarily perceptual (the arch is perceived similarly) but evaluative (the arch is interpreted differently). The perceptual implicit response may be similar across cultures; the explicit evaluative overlay diverges. Cultural differences should be detectable primarily in late ERP components (P300 and beyond) rather than early components (N1, P1), because the late components reflect evaluative processing.

**Architectural consequence**: "Universal" design principles based on perceptual fluency (fractal dimension, golden ratio, biophilic features) have more cross-cultural validity than design principles based on semantic meaning (stylistic reference, symbolic form, narrative content). But both are operative, and in any real building the semantic layer powerfully modulates the perceptual layer.

## 3.3 Derived Architectural Principles

### DAP1: The Alignment Principle
Environments produce optimal wellbeing when the implicit and explicit channels are aligned — when the space both *feels* right (Type 1) and *is judged* right (Type 2). Misalignment produces measurable stress (ACC activation, autonomic perturbation, decreased confidence).

### DAP2: The Activity-Tuning Principle
Environments cannot be optimized in the abstract. They can only be optimized for specific activity frames. Multi-activity environments require either spatial zoning (different areas tuned for different activities) or temporal adaptability (features that can be reconfigured for different activities at different times).

### DAP3: The Expertise-Relativity Principle
Design quality is expertise-relative. What constitutes a "good" space depends on the occupant's processing history. Design for naïve occupants requires attention to surface features and immediate perceptual quality. Design for expert occupants requires attention to structural relationships and deeper spatial syntax.

### DAP4: The Implicit Foundation Principle
Under conditions that degrade PFC function — stress, fatigue, cognitive load, developmental immaturity, neurological impairment — the implicit channel dominates. Environments for vulnerable populations must be designed primarily at the implicit level (biophilic, restorative, low-complexity, warm-material) because the explicit channel cannot be relied upon.

### DAP5: The Sedimentation Principle
Environmental quality shapes its own future evaluation. Positive explicit engagement with a space (admiring its design, enjoying its atmosphere, learning its features) sediments into more positive implicit processing over time. Negative explicit engagement sediments into more negative implicit processing. First encounters therefore have disproportionate long-term impact because they set the sedimentation trajectory.

### DAP6: The Reengagement Principle
Static environments produce complete habituation and lose their capacity to trigger explicit engagement. Environments that support long-term wellbeing require features that periodically reawaken salience detection — dynamic elements (changing light, seasons, growth), progressive disclosure (features that reveal new layers over time), or adaptive elements (reconfigurability that refreshes the spatial experience).

### DAP7: The Channel Separation Measurement Principle
Post-occupancy evaluation must measure implicit and explicit channels separately. Combined ratings (e.g., "rate your satisfaction with this space on a 1–7 scale") conflate the two channels and produce systematic artifacts: aligned spaces get extreme ratings, misaligned spaces get moderate-but-variable ratings. Proper evaluation requires: (a) implicit measures (autonomic, eye-tracking, behavioral), (b) explicit measures (verbal report, rating scales), and (c) conflict measures (response latency, confidence, ACC indicators).

### DAP8: The Cost-of-Control Design Principle
Environments that require sustained explicit control for appropriate use are inherently fatiguing. If a space requires occupants to constantly override their implicit approach/avoidance tendencies (e.g., persisting in a noisy, uncomfortable workspace because the task demands it), the cognitive cost is real and cumulative. Good design minimizes the cost of control by aligning the space's implicit affordances with its intended activity frame.

### DAP9: The Semantic Investment Principle
Investing in the meaning and narrative of a space (branding, wayfinding narrative, cultural programming, historical interpretation) is not superficial — it shapes the explicit channel, which then reconfigures implicit processing. A hospital that communicates "place of healing" through its signage, art, and spatial narrative activates a different explicit frame (and therefore a different implicit processing ecology) than a hospital that communicates "place of institutional efficiency."

### DAP10: The Temporal Asymmetry Principle
First-encounter design features (dramatic entrances, wayfinding clarity, initial affective impact) and long-term occupancy features (material durability, acoustic comfort, spatial flow, daylight quality) operate through different neural systems (hippocampal/novel-DA vs. striatal/habitual-low-DA). Optimizing for one does not optimize for the other. Both must be designed for explicitly, with the understanding that they serve different neurobiological functions.

## T_IE_001: Activity-Frame Complexity Retuning

**Antecedent conditions**: Physical environment E with complexity level C (operationalized as fractal dimension, edge density, color diversity, or information-theoretic entropy). Person P shifts from activity frame A₁ (focused work: report completion, data analysis) to activity frame A₂ (creative exploration: brainstorming, design ideation).

**Predicted outcome**: 
- C_opt(A₂) > C_opt(A₁): The optimal complexity for positive affect and performance shifts upward under the exploratory frame.
- Performance under A₁ peaks at lower C than under A₂ (inverted-U peak shifts right).
- At complexity levels above C_opt(A₁) but below C_opt(A₂), A₁ performance degrades while A₂ performance improves.

**Moderating variables**: 
- Domain expertise (experts tolerate higher complexity in both frames; main effect of expertise + interaction with frame)
- Working memory capacity (higher WMC → larger shift between frames, because WMC enables the wider attentional scope required by exploration)
- Current cognitive load (external load narrows the tolerance band for both frames, reducing the shift between them)
- Introversion/extraversion (extraverts show larger shift toward higher complexity under exploration)

**Expected effect sizes**: 
- Complexity preference shift between frames: d ≈ 0.4–0.7
- Performance crossover (same complexity, different frames): d ≈ 0.5–0.8
- Expertise moderation: interaction β ≈ 0.15–0.25

**Neural signature**: Higher frontal theta (4–8 Hz) at the moment of frame shift (working memory engagement for new goal). Shift in posterior alpha power topography (parietal alpha suppression broader under exploration, narrower under focus). Beta-frequency PFC–posterior coherence reconfigures within 200–500ms of instruction.

**Architectural test case**: Open-plan office with adjustable environmental complexity (movable screens, variable lighting complexity, adjustable visual density). Within-subjects design: same participants complete focused work task and creative brainstorming task in same physical space at varying complexity levels. Dependent variables: task performance, self-reported affect, eye-tracking (fixation entropy as implicit complexity processing measure), EEG.

## T_IE_002: Expertise-Modulated Aesthetic Divergence

**Antecedent conditions**: Architectural space S with feature set F (spanning canonical to unconventional designs). Two groups: architects with ≥10 years professional experience (Group E) and non-design laypersons (Group L).

**Predicted outcome**:
- E and L show significantly different aesthetic ratings for the same spaces.
- The divergence is greatest for unconventional designs (where explicit aesthetic frameworks matter most) and smallest for universally pleasant environments (where implicit perceptual fluency dominates).
- The divergence is *mediated* by different implicit processing profiles: E and L show different fixation patterns, different SCR patterns, different ERP topographies.
- Mediational model: Expertise → Altered implicit processing → Different aesthetic evaluation.

**Moderating variables**:
- Type of architectural education (modernist-trained architects vs. classically-trained architects diverge from each other as well as from laypersons)
- Cultural background (cross-cultural expertise differences)
- Presentation modality (photographs vs. VR vs. real building; divergence should increase with ecological validity because experts extract more from richer stimuli)

**Expected effect sizes**:
- Evaluative rating divergence: d ≈ 0.6–1.0
- Eye-tracking: experts show more distributed fixation (higher scanpath entropy), shorter mean fixation duration (more efficient feature extraction): d ≈ 0.5–0.8
- ERP: experts show earlier and larger P300 to architectural anomalies (faster salience detection for domain-relevant features): d ≈ 0.4–0.6
- Autonomic: experts show lower SCR to unconventional designs (reduced arousal due to familiarity with the category): d ≈ 0.3–0.5

**Neural signature**: Experts show greater functional connectivity between visual cortex and left temporal semantic network (semantic knowledge guides perception). Laypersons show stronger amygdala–visual cortex connectivity (affective/hedonic route dominates). Both patterns are detectable with fMRI; the eye-tracking and ERP signatures are deployable in ecologically valid settings.

**Architectural test case**: Present VR environments spanning canonical to experimental designs. Record eye movements, EEG, SCR, and aesthetic ratings simultaneously. Test mediational model: does controlling for implicit processing differences (fixation entropy, SCR) eliminate the expertise effect on ratings?

## T_IE_003: Semantic Override of Perceptual Fluency

**Antecedent conditions**: Space S is perceptually fluent (high symmetry, golden-ratio proportions, warm materials, natural light — produces positive Type 1 response). Person P has strong negative semantic associations with S (moral objection to the organization housed there, traumatic personal history, cultural stigma).

**Predicted outcome**: 
- Implicit measures (SCR, HR deceleration, early ERP components, eye-tracking fluency) show positive response to S.
- Explicit evaluation is negative.
- ACC conflict signal detected (increased dACC activation, ERN/N2 amplitude increase, response latency increase, confidence decrease).
- Under cognitive load (concurrent dual task), the negative explicit evaluation weakens and the positive implicit response dominates — evaluation shifts toward positive.

**Moderating variables**:
- Strength of semantic association (stronger negative meaning → stronger override)
- Salience of the semantic cue (if the negative meaning is salient vs. must be recalled)
- Cognitive load (load weakens explicit override)
- Individual differences in need for cognition (high NFC → stronger override maintenance)

**Expected effect sizes**:
- Fluency–evaluation dissociation (positive implicit, negative explicit): d ≈ 0.5–0.8
- ACC conflict signal: d ≈ 0.4–0.6
- Response latency increase: d ≈ 0.3–0.5
- Cognitive load moderation: under load, override weakens by d ≈ 0.3–0.5

**Neural signature**: dlPFC activation (explicit evaluation) co-occurring with medial OFC positive hedonic signal (implicit pleasure), with dACC activation mediating the conflict. Under cognitive load, dlPFC activation decreases and medial OFC signal dominates.

**Architectural test case**: Present identical VR environments with and without negative semantic information (building attributed to morally controversial organization vs. neutral organization). Between-subjects attribution manipulation, within-subjects cognitive load manipulation. Measure implicit (SCR, eye-tracking) and explicit (rating, verbal report) channels separately.

## T_IE_004: Real-Time Activity Frame Shift (The Bridge Mechanism)

**Antecedent conditions**: Person P navigates real or VR space S under activity frame A₁. At time t, P receives instruction or decides to shift to activity frame A₂ (e.g., from "enjoy the walk" to "evaluate the wayfinding system" or from "casual browsing" to "find room 347").

**Predicted outcome**:
- Within 200–500ms: PFC beta power spectrum reconfigures (detectable with EEG/MEG).
- Within 500ms–2s: Fixation patterns change (eye-tracking scanpath divergence from pre-shift baseline).
- Within 1–3s: Autonomic profile shifts (SCR, HR reflect new salience landscape).
- Within 3–10s: Behavioral indicators of new frame (movement speed, exploration pattern, verbal behavior change).
- After shift: same physical features produce different salience (measured by dwell time), different affective valence (measured by SCR to specific features), and different aesthetic evaluation (measured by concurrent verbal report or post-trial rating).

**Moderating variables**:
- Familiarity with A₂ (practiced frames shift faster; measured by shift latency)
- Similarity between A₁ and A₂ (similar frames → smaller reconfiguration; measured by pre/post scanpath correlation)
- Cognitive flexibility (individual difference; measured by Wisconsin Card Sort or Trail-Making B)
- Environmental support for frame shift (does the space cue the new frame through signage, layout change, or social context?)

**Expected effect sizes**:
- Scanpath divergence (pre vs. post shift): d ≈ 0.6–0.9
- EEG reconfiguration: frontal beta power shift detectable within 200–500ms: d ≈ 0.5–0.7
- Autonomic shift: SCR latency 1–3s: d ≈ 0.3–0.5
- Evaluation change for same features: d ≈ 0.4–0.7

**Neural signature**: Frontopolar cortex (BA 10) activation at the moment of frame shift (superordinate goal change). Rapid reconfiguration of PFC–posterior connectivity (fMRI dynamic connectivity). Salience network (AI/dACC) activation at the transition point (gating the switch). CEN engagement replacing prior network configuration.

**Architectural test case**: Participants in VR building. Mid-trial instruction: "You are now evaluating this space for [new purpose]." Continuous recording of eye movements, EEG, SCR, HR. Pre/post comparison of all channels. Critical control: no instruction change (time-matched), to ensure observed changes are due to frame shift rather than temporal drift.

## T_IE_005: Cost-Gated Explicit Engagement Threshold

**Antecedent conditions**: Person P walking through space S. Environmental novelty/complexity gradually increases along the path. P is currently in Type 1 autopilot mode.

**Predicted outcome**:
- Below threshold: implicit processing handles the environment. No frontal theta increase, no pupil dilation increase, no dACC activation above baseline.
- At threshold: salience network detects novelty/discrepancy exceeding EVC threshold. Frontal theta increases (working memory engagement), pupil dilates (LC-NE arousal), dACC activates.
- Above threshold: Type 2 engages. Fixation patterns shift from stimulus-driven to goal-directed. Movement speed decreases (information-gathering mode). Verbal behavior changes (comments about the space).

**Moderating variables**:
- Task importance (high-stakes task → lower threshold, earlier engagement)
- Current stress level (high stress → higher threshold, later engagement — PFC degraded)
- Need for cognition (high NFC → lower threshold)
- Fatigue (fatigue → higher threshold)
- Environmental support (clear danger signals → lower threshold via amygdala bypass)

**Expected effect sizes**:
- Pupil dilation at threshold crossing: d ≈ 0.5–0.7
- Frontal theta increase: d ≈ 0.4–0.6
- Movement speed decrease: d ≈ 0.3–0.5
- Task importance moderation: shifts threshold by d ≈ 0.4

**Architectural test case**: Participants walk a corridor with gradually increasing visual complexity (controlled via projection or VR). Continuously measure pupil size, frontal theta (mobile EEG), movement speed, and SCR. Identify the threshold via change-point analysis. Vary task importance (told this is "just exploration" vs. "you need to find a specific room") to test EVC modulation.

## T_IE_007: The Café Paradox — Working in Suboptimal Environments

**Antecedent conditions**: Person P chooses to work in space S_café (high noise, crowded, non-ergonomic) over space S_office (quiet, designed for work, ergonomic). P's explicit framing: "working in a café makes me feel productive/creative/connected."

**Predicted outcome**:
- Implicit measures in S_café show higher arousal, more distraction (increased SCR, more fixation interruptions, elevated cortisol).
- Explicit measures show higher satisfaction, higher self-reported productivity, more positive affect.
- Channel misalignment: implicit measures are worse; explicit measures are better.
- Actual task performance: depends on task type. Routine tasks: S_office superior. Creative tasks: S_café may be equivalent or superior (moderate arousal from social stimulation may enhance divergent thinking — the Mehta, Zhu, & Cheema, 2012 ambient noise effect).

**Expected effect sizes**:
- Implicit stress measures: S_café > S_office by d ≈ 0.3–0.5
- Explicit satisfaction: S_café > S_office by d ≈ 0.2–0.4
- Performance: task-type dependent. Routine: S_office superior by d ≈ 0.3. Creative: no significant difference or small S_café advantage d ≈ 0.1–0.2.

**Architectural implication**: Self-reported environmental preference does not track objective implicit-channel optimality. People choose environments that satisfy explicit psychological needs (social identity, sense of productivity, variety) even when the implicit channel is suboptimal. Design evaluation must not rely solely on stated preference.

## T_IE_008: Trauma-Space Interaction

**Antecedent conditions**: Person P with PTSD (trauma associated with specific environmental features — acoustic properties resembling combat, spatial configuration resembling site of assault, lighting conditions resembling trauma context). P enters space S that contains trauma-associated features.

**Predicted outcome**:
- Amygdala activation produces rapid threat response (Type 1): elevated HR, SCR, startle reflex, hypervigilance (fixation on threat-associated features).
- Explicit knowledge ("I am safe, this is a different place") engages PFC to attempt regulation.
- Override success depends on: PFC integrity (diminished in chronic PTSD), current stress load, similarity of trauma cue to original trauma, availability of safety signals.
- ACC conflict signal: detected even when override is successful (the conflict between amygdala threat signal and PFC safety assessment is always present; resolution ≠ absence of conflict).

**Moderating variables**:
- Time since trauma (recent → stronger conditioning, weaker extinction)
- Treatment history (CBT/exposure therapy strengthens PFC override circuits)
- Feature similarity (closer match to trauma context → stronger amygdala response)
- Social support present (co-regulation reduces amygdala response)

**Expected effect sizes**:
- Amygdala response to trauma-similar features vs. neutral: d ≈ 0.8–1.5
- PFC override success rate: ~40–60% for untreated PTSD, ~70–85% for treated
- ACC conflict signal even during successful override: d ≈ 0.4–0.6

**Architectural consequence**: Trauma-informed design must identify and eliminate implicit threat triggers. Physical features — specific acoustic properties, lighting levels, spatial enclosure ratios, material textures — that resemble common trauma contexts should be avoided or mitigated. Explicit reassurance (signage, verbal communication) is a supplement, not a substitute, because the implicit channel processes faster and may overwhelm the explicit.

## T_IE_009: The McMansion Effect — Explicit Rejection of Implicit Pleasure

**Antecedent conditions**: Architectural design D has high surface appeal (large scale, symmetrical, materially rich, conforming to evolutionary preference signals) but violates compositional principles known to architecturally educated observers (incoherent proportional system, arbitrary ornament, facade composition without underlying spatial logic).

**Predicted outcome**:
- Architecturally naïve observers: positive implicit response + positive explicit evaluation. Channels aligned. High ratings, high confidence, fast response.
- Architecturally educated observers: positive implicit response (perceptual fluency, material richness) + negative explicit evaluation ("it's tasteless," "the proportions are wrong"). Channel conflict. ACC activation, response latency increase, confidence decrease.
- Between-group difference in evaluation: large (d ≈ 0.8–1.2).
- Between-group difference in implicit measures: small (d ≈ 0.1–0.3) — both groups have positive implicit responses.
- The educated group's negative evaluation is driven by the explicit aesthetic framework overriding implicit pleasure.

**Neural signature**: Educated group shows dlPFC activation concurrent with positive medial OFC signal, with dACC mediating the conflict. Naïve group shows aligned OFC + vmPFC positive signal without dlPFC conflict engagement.

**Architectural consequence**: Design quality as judged by informed observers is not the same as design quality as experienced by naïve occupants. Both are "real" — they reflect different points on the expertise sedimentation continuum. Design education literally changes the brain's response to architecture. This is not elitism; it is a neuroscientific fact about how training reshapes implicit processing.

## T_IE_010: Wayfinding Under Different Goal States

**Antecedent conditions**: Complex building B with low spatial legibility (deep spatial graph, few landmarks, ambiguous circulation). Person P navigates B under two conditions: A₁ (urgent goal: find specific room quickly) and A₂ (exploratory: discover the building at leisure).

**Predicted outcome**:
- Under A₁ (urgency): low legibility → high negative PE → frustration, anxiety, negative evaluation. The complexity that produces PE under urgency is the *wayfinding-relevant* complexity (circulation legibility, signage clarity).
- Under A₂ (exploration): low legibility → high positive PE → curiosity, engagement, positive evaluation. The complexity that produces PE under exploration is the *experiential* complexity (spatial discovery, architectural richness).
- Same physical space, same complexity level, opposite affective valence — driven by activity-frame-dependent PE interpretation.

**Expected effect sizes**:
- Evaluation difference (same space, different frames): d ≈ 0.7–1.0
- Wayfinding efficiency: A₁ > A₂ (urgency produces more focused search, despite frustration): d ≈ 0.3–0.5
- Anxiety measures (SCR, HR): A₁ >> A₂: d ≈ 0.5–0.8

**Architectural consequence**: Wayfinding systems must be designed for the highest-urgency expected activity frame. If a space will be used by people in urgent search (hospitals, airports, emergency exits), legibility at the wayfinding level must be maximized regardless of whether this reduces experiential complexity. The two types of complexity can be partially orthogonalized: a building can have high experiential complexity (rich architectural vocabulary) with high wayfinding legibility (clear circulation hierarchy, prominent landmarks, effective signage).

## T_IE_011: Sacred Space and Ritual Loading

**Antecedent conditions**: Space S has features associated with sacred architecture (vast height, filtered light, symmetry, acoustic resonance). Person P₁ has cultural knowledge and religious commitment (explicit: "this is sacred ground"). Person P₂ has no such associations.

**Predicted outcome**:
- Both P₁ and P₂ have implicit responses to the physical features: awe (height), calm (filtered light), solemnity (acoustic resonance). These are biophilic/embodied responses operating through the implicit channel.
- P₁ additionally activates explicit religious framework: episodic memories of prior rituals, semantic knowledge of sacred significance, social identity as believer. This amplifies the implicit response and adds a meaning layer.
- P₁'s total response > P₂'s total response, and the difference is driven by the explicit channel.
- Under cognitive load, P₁'s response moves toward P₂'s (explicit contribution degraded).

**Expected effect sizes**:
- P₁ vs. P₂ evaluation difference: d ≈ 0.5–0.9
- Implicit measures (SCR, HR) difference: d ≈ 0.1–0.3 (physical features affect both similarly)
- Explicit measures (meaning, significance, emotional depth) difference: d ≈ 0.7–1.2
- Cognitive load moderation of P₁'s response: d ≈ 0.3–0.5

**Architectural consequence**: Sacred architecture derives its power from alignment of implicit and explicit channels. The physical features (height, light, acoustics) produce positive implicit responses that are then *amplified* by the explicit cultural framework. Remove the physical features (a sacred space in a strip mall) and you lose the implicit amplification. Remove the cultural framework (a cathedral experienced by a secular tourist) and you lose the explicit amplification. Maximum impact requires both.

## T_IE_012: Habituation Breakage and Re-Seeing

**Antecedent conditions**: Person P has occupied space S for extended period (months/years). Processing of S is fully habituated — Type 1 autopilot, no salience detection, S is "invisible." At time t, an event triggers re-seeing: (a) a visitor comments on S, (b) P returns to S after an absence, (c) a physical change occurs in S, (d) P's mood/stress state shifts.

**Predicted outcome**:
- Re-seeing triggers salience network activation (AI/dACC).
- CEN engages: P explicitly attends to features of S that had been habituated.
- Evaluation of S may be more positive than during habituation (if re-seeing reveals previously unappreciated qualities) or more negative (if re-seeing reveals previously unnoticed deficiencies).
- The re-seeing event produces a temporary spike in frontal theta, pupil dilation, and exploratory eye movement (reduced fixation predictability).
- Duration of re-seeing: brief (minutes to hours) before re-habituation begins.

**Architectural consequence**: Environments that support periodic re-seeing maintain higher long-term occupant satisfaction. Design strategies: seasonal variation in daylight, living elements that change (plants, water), material patina that evolves, spaces with "hidden" features revealed by changing light conditions or extended exploration.

## 6.3 Critical Tests of Superordinate Status

The superordinate claim (C1) is falsifiable. It would be refuted if:
- The Goldilocks optimum for *any* environmental variable proved to be activity-frame-invariant (same optimum regardless of what the person is doing).
- Physical design features predicted environmental response equally well regardless of explicit knowledge, expertise, or semantic associations.
- Implicit and explicit channels never diverged (no conflict detection, no McMansion effect, no placebo architecture).

Conversely, every demonstration that activity frame shifts the optimum, that expertise alters the response, or that semantic content overrides physical properties is confirmatory evidence for superordinate status.
