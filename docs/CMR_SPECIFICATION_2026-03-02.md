# PART I: CONCEPTUAL FOUNDATIONS

## 1.1 What CMR Is

Compositional Mechanism Reasoning is the systematic derivation of novel, testable predictions by composing causal mechanisms across multiple theoretical frameworks. It transforms raw empirical findings into hypotheses that can guide future research.

Unlike:
- **Bayesian Network inference** (parameter estimation on a fixed graph)
- **Coherence assessment** (constraint satisfaction across belief network)
- **Entrenchment dynamics** (confidence adjustment based on evidence)

CMR **generates new reasoning outputs** — predictions not contained in either the finding or any single framework. It is how Article Eater functions as a scientific discovery partner, not merely a knowledge repository.

### 1.1.1 Philosophical Foundations

CMR rests on three foundational frameworks from philosophy of science:

**1. Mechanism Discovery (Darden & Craver, 2002; Machamer et al., 2000)**

A mechanism consists of entities performing activities that produce changes. Each mechanistic step specifies:
- **Entity A** performs **Activity X** which produces **Change in Entity B**

The mechanism is *productive* — each step makes a contribution to the overall outcome. No step can be arbitrary or speculative at the "how-actually" maturity level.

**2. Interventionist Causation (Woodward, 2003)**

A causal claim "X causes Y" is true if and only if there exists an intervention on X that would change Y. Predictions are generated by asking w-questions: "What if we intervened on component X?"

**3. Structure-Mapping Theory (Gentner, 1983; Holyoak & Thagard, 1989)**

Analogical reasoning operates through structural alignment — matching relational structures rather than surface features. Templates are most productive when they transfer across domains with different entities but isomorphic causal structures.

| Operation | Input | Output | Example |
|-----------|-------|--------|---------|
| **Template matching** | Finding, framework library | Ranked list of matching frameworks | "Nature view" matches predictive-processing framework |

# PART II: FINDING-MECHANISM LINKS

## 2.1 Definition and Purpose

A **FindingMechanismLink** connects an empirical finding (Tier 3 claim) to the theoretical mechanisms (Tier 1 → Tier 2 template chains) that explain it.

### 2.1.1 Source and Target

- **Source**: Empirical finding (Tier 3 belief node)
  - Example: "Nature exposure reduces hospital recovery time by 11 days (p < 0.001)"
  - Must be of type `empirical_finding` or `synthesis_conclusion`

- **Target**: Mechanistic template (Tier 2 node) or template chain (composition of Tier 2 templates)
  - Example: "Predictive-processing framework's visual-statistics template"
  - May be single template or composition of multiple templates across frameworks

### 2.1.2 Why This Matters

Without explicit finding-mechanism links, the system cannot:
1. Trace which mechanisms CMR used to generate a given prediction
2. Identify which mechanisms are supported by converging evidence
3. Build an auditable derivation chain from finding to prediction
4. Compute confidence in predictions based on confidence in supporting mechanisms
5. Detect when multiple independent mechanisms support the same prediction

## 2.2 FindingMechanismLink Data Model

```python
from enum import Enum
from dataclasses import dataclass
from typing import List, Optional, Dict, Any

class MechanismExplanationType(str, Enum):
    """Types of finding-mechanism relationships."""
    DIRECTLY_EXPLAINS = "directly_explains"        # Mechanism M fully explains finding F
    PARTIALLY_EXPLAINS = "partially_explains"      # M explains aspect of F (e.g., physiological but not affective)
    MODULATES = "modulates"                        # M modulates magnitude/direction of F
    MEDIATES = "mediates"                          # M is on causal pathway for F
    CONTRADICTS = "contradicts"                    # M predicts opposite of F
    CONDITIONAL_EXPLAINS = "conditional_explains"  # M explains F under specific conditions


class MechanismStepEvidence(str, Enum):
    """Type of evidence supporting a finding-mechanism link at each step."""
    DIRECT_TEST = "direct_test"           # Finding directly tests this step (e.g., measured cortisol)
    INDIRECT_SUPPORT = "indirect_support" # Finding supports via proxy measure
    LOGICAL_INFERENCE = "logical_inference" # Step is logically required but not directly measured
    ANALOGY = "analogy"                   # Step inferred by analogy to similar mechanism


@dataclass
class MechanismStep:
    """Single step in a mechanism chain."""
    step_number: int                                # Position in the chain (0-indexed)
    from_entity: str                                # Entity performing the activity
    activity: str                                   # What the entity does
    to_entity: str                                  # Entity that changes
    change_produced: str                            # How the entity changes
    level: str                                      # Level of analysis: ecological/computational/circuit/cellular/molecular
    maturity: str                                   # how-possibly/how-plausibly/how-actually
    evidence_type: MechanismStepEvidence           # What kind of evidence supports this step
    evidence_citation: Optional[str] = None        # Paper or study supporting this step
    confidence: float = 0.5                         # 0-1: confidence in this step
    bridging_quality: str = "MEDIUM"              # Level bridge quality: LOW/MEDIUM/HIGH


@dataclass
class FindingMechanismLink:
    """
    Connects an empirical finding to mechanism(s) that explain it.

    This is the primary data structure enabling CMR evidence propagation.
    """

    # Identity
    link_id: str                                    # Unique identifier (finding_id + template_id)
    finding_id: str                                 # Tier 3 empirical finding being explained
    finding_description: str                        # Human-readable finding text

    # Mechanistic explanation
    template_id: str                                # Tier 2 template doing the explaining
    template_name: str                              # Human name (e.g., "predictive-processing-visual-statistics")
    framework_id: str                               # Tier 1 framework containing template
    framework_name: str                             # Human name (e.g., "predictive-processing")

    # Explanation type and evidence chain
    explanation_type: MechanismExplanationType      # How the mechanism explains the finding
    mechanism_steps: List[MechanismStep]            # Causal chain from stimulus to outcome

    # Confidence in the link
    overall_confidence: float                       # 0-1: how confident is this explanation
    confidence_justification: str                   # Why we have this confidence level

    # Evidence at finding-mechanism interface
    finding_measure_type: str                       # What was measured in the finding
    mechanism_prediction: str                       # What the mechanism predicts
    measure_alignment: str                          # How well finding measures match mechanism prediction
                                                    # "perfect" / "adequate" / "loose" / "misaligned"

    # Scope and conditions
    scope_conditions: Dict[str, Any]               # When this mechanism applies
                                                    # {"population": [...], "context": [...], "conditions": [...]}

    # Prediction generation
    derived_predictions: List[str]                 # Predictions generated from this mechanism
    prediction_grammar_operations: List[str]       # Which w-question operations were used
                                                    # e.g., ["SUBSTITUTE_CAUSE", "VARY_MODERATOR", "BLOCK_PATHWAY"]

    # Convergence information
    converges_with_frameworks: List[str]           # Other frameworks that predict the same finding
    convergence_independence: str                  # "low" / "medium" / "high" - how independent are the frameworks

    # Cross-checking
    alternatives_considered: List[str]             # Other mechanisms that were evaluated
    why_best_explanation: str                      # Why this mechanism is the best fit

    # Metadata
    source_paper: Optional[str] = None             # Which paper provided the finding
    created_at: str = ""                           # ISO timestamp
    maturity_status: str = "proposal"              # proposal / validated / refuted
    notes: Optional[str] = None


# Registry for all finding-mechanism links
FINDING_MECHANISM_LINKS: Dict[str, FindingMechanismLink] = {}
```

### 2.2.1 Field Descriptions

**identity**: `link_id`, `finding_id`, `finding_description`
- Uniquely identifies the link and points to the finding it explains
- `link_id` format: `FML-{finding_id}-{template_id}`

**mechanistic explanation**: `template_id`, `template_name`, `framework_id`, `framework_name`
- Specifies which template and framework provide the explanation
- Templates are Tier 2; frameworks are Tier 1

**explanation type**: `explanation_type`
- **DIRECTLY_EXPLAINS**: Mechanism accounts for all major aspects of the finding
- **PARTIALLY_EXPLAINS**: Mechanism explains some aspects (e.g., physiological pathway but not affective outcome)
- **MODULATES**: Mechanism modulates magnitude or sign of the finding
- **MEDIATES**: Mechanism is one pathway among several that produce the finding
- **CONTRADICTS**: Mechanism predicts the opposite; finding challenges the framework
- **CONDITIONAL_EXPLAINS**: Mechanism explains the finding only under specified conditions

**mechanism_steps**: Causal chain from stimulus to outcome
- Each step specifies entity, activity, change, level, and evidence type
- Levels (Craver, 2007): ecological → computational → circuit → cellular → molecular
- Evidence types: direct-test (measured), indirect-support (proxy), logical-inference (required), analogy (inferred)
- Maturity: how-actually (confirmed), how-plausibly (supported), how-possibly (speculative)

**confidence**: `overall_confidence`, `confidence_justification`
- Overall 0-1 confidence score
- Determined by:
  - Weakest link in the mechanism chain (how-actually links strengthen it, how-possibly weaken it)
  - Measure alignment: does the finding actually measure what the mechanism predicts?
  - Replications and independent evidence
  - Scope match: does the finding's population/context match the mechanism's scope?

**evidence at interface**: `finding_measure_type`, `mechanism_prediction`, `measure_alignment`
- Critical quality check: Does the finding actually measure the mechanism's prediction?
  - "perfect": Mechanism predicts cortisol, finding measures cortisol
  - "adequate": Mechanism predicts HPA axis, finding measures stress hormones broadly
  - "loose": Mechanism predicts stress, finding measures recovery time (proxy)
  - "misaligned": Mechanism predicts neural activation, finding only measures behavior

**scope conditions**: Specifies when the mechanism applies
- Population: which demographic groups
- Context: which environmental/cultural contexts
- Conditions: temporal, developmental, pathological conditions
- Example: "Adult humans in Western post-industrial societies; acute stress contexts"

**prediction generation**: How CMR uses this link
- `derived_predictions`: List of novel predictions generated from this mechanism
- `prediction_grammar_operations`: Which interventionist operations generated these predictions
  - SUBSTITUTE_CAUSE: "If the cause is X, not Y, then..."
  - VARY_MODERATOR: "If moderator M changes, then..."
  - BLOCK_PATHWAY: "If we block the pathway, then..."
  - CHANGE_TEMPORAL_CONTEXT: "If timing changes, then..."
  - VARY_INDIVIDUAL: "If individual characteristics change, then..."
  - CROSS_CULTURAL_VARIATION: "In different cultures, then..."

**convergence**: `converges_with_frameworks`, `convergence_independence`
- Which other frameworks independently predict the same finding?
- Are they truly independent (different theoretical origins, neural substrates) or dependent (shared core assumptions)?
- Higher independence = stronger warrant for the prediction

**alternatives**: `alternatives_considered`, `why_best_explanation`
- Which other mechanisms were evaluated and rejected?
- Explicit reasoning for why this is the best fit
- Encourages comparative evaluation

**maturity status**: `maturity_status`
- proposal: Initial finding-mechanism link; validation pending
- validated: Multiple studies confirm the mechanism explains the finding
- refuted: Evidence contradicts the mechanism; link should be deprecated

# PART III: THE CMR PIPELINE

## 3.1 Eight-Step Process

CMR operates in a clearly defined sequence. Each step has prerequisites, operations, and outputs.

### Step 1: Finding Decomposition
**Input**: Empirical finding (Tier 3 claim)
**Operation**: Decompose into causal variables
**Output**: Structured variable set with roles

Example: "Nature exposure reduces hospital recovery time by 11 days"
- **Stimulus features**: Natural scene properties (1/f spectral statistics, biophilic elements, spatial openness)
- **Perceptual processes**: Visual processing, scene perception, scene understanding
- **Outcome measures**: Recovery time, pain medication use, infection rates, mood
- **Population**: Post-surgical patients (n=120)
- **Context**: Urban hospital with windows (Ulrich, 1984)
- **Unobserved mediators**: Cortisol, immune function, sleep, pain perception

### Step 2: Framework Matching
**Input**: Decomposed variables + reasoning goal
**Operation**: Retrieve frameworks whose scope covers variables
**Output**: Ranked matched frameworks with match quality

Matching is parameterized by reasoning goal:
- **Goal = "explain"**: Retrieve frameworks with complete causal chains (stimulus → outcome)
- **Goal = "predict"**: Retrieve frameworks with intervention points
- **Goal = "find boundary conditions"**: Retrieve frameworks with scope conditions
- **Goal = "identify cultural variation"**: Retrieve frameworks with population/context parameters

Retrieval operates on structural level (Gentner, 2004):
- Surface level: specific entities, brain regions, measures
- Structural level: relational roles, optimization principles, organizing patterns

Example matches for "nature exposure" finding:
1. **Predictive-processing** (HIGH): Matches via "stimulus statistics → prediction error → metabolic efficiency"
2. **DMN/TPN dynamics** (MEDIUM): Matches via "low attention demand → DMN engagement → parasympathetic"
3. **Interoceptive-inference** (MEDIUM): Matches via "physiological state prediction → affect construction"
4. **Spatial-navigation** (LOW): Distant match via affordance perception

### Step 3: Mechanism Tracing
**Input**: Matched frameworks + relevant mechanistic templates
**Operation**: Trace causal chain from stimulus through intermediaries to outcome
**Output**: Leveled, maturity-tagged mechanism traces

Each link in the trace specifies:
```
from_entity → activity → to_entity | change | level | maturity | evidence_type
```

Example trace (predictive-processing framework):
```
Visual cortex V1
  → efficient coding of 1/f spectrum
  → prediction error signal
  | reduced prediction error magnitude | circuit | how-actually | direct_test
  [Evidence: Rao & Ballard 1999; Olshausen & Field 1996]

Anterior cingulate (error signal)
  → precision weighting computation
  → thalamic reticular nucleus
  | reduced thalamic gating | circuit | how-plausibly | indirect_support
  [Evidence: Friston et al. 2012]

Locus coeruleus (noradrenergic)
  → neuromodulatory output
  → broad cortical activation
  | reduced noradrenergic arousal | cellular | how-actually | indirect_support
  [Evidence: Aston-Jones & Cohen 2005; arousal measured via pupil dilation]

HPA axis
  → cortisol secretion
  → systemic circulation
  | reduced cortisol concentration | molecular | how-actually | direct_test
  [Evidence: Ulrich 1984 measured cortisol; Kaplan et al. 1989]

... (additional steps) ...
```

**Rule**: A mechanism chain is only as strong as its weakest link.
- If any step is only "how-possibly", the entire chain's confidence is reduced
- If any measurement is "logical-inference" (not measured), the chain has a gap

### Step 4: Cross-Framework Composition
**Input**: Multiple mechanism traces from different frameworks
**Operation**: Check for compatibility; identify interference patterns
**Output**: Composed mechanism chain with interference notes

When combining traces from independent frameworks:

- **Serial composition** (A then B): ω_eff = ∏ω_i, d_eff = min(d_i), δ_eff = min(δ_i)
  - Effect = product of individual effects
  - Duration = shortest individual duration
  - Decay = fastest individual decay

- **Parallel composition** (A and B independently): Log-odds sum
  - ln(odds_eff) = Σ ln(odds_i)
  - Effective support = sum of log-odds from independent evidence

**Interference checks**:
- Do the mechanisms share neural substrates? (If yes, likely not truly additive)
- Are there compensatory feedback loops? (e.g., if cortisol is reduced, HPA might increase production)
- Are there ceiling/floor effects? (e.g., if cortisol is already near zero, can't reduce further)
- Known modularity violations (Woodward's Critique 8): Some interventions disrupt unintended systems

### Step 5: Prediction Generation
**Input**: Composed mechanism chain
**Operation**: Generate novel testable predictions using interventionist w-questions
**Output**: Set of predictions with derivation chains and testability assessments

Six prediction types (from Woodward, 2003):

1. **Substitute the cause**: If the cause is X (not Y), then...
   - "If the mechanism is 1/f spectral match (not natureness per se), then artificial fractals should produce the same effect"

2. **Vary the moderator**: If moderator M changes, then...
   - "If the mechanism goes through noradrenergic reduction, then high-anxiety patients (higher baseline arousal) should benefit more"

3. **Block the pathway**: If we intervene to block the pathway, then...
   - "If noradrenergic reduction is key, then beta-blockers should not affect the benefit (they block a different pathway)"

4. **Change temporal context**: If timing changes, then...
   - "If cortisol reduction is key, the effect should be largest when cortisol is highest (pre-operative)"

5. **Vary the individual**: If individual characteristics change, then...
   - "If affect is constructed from interoceptive prediction, then alexithymic patients should show physiological benefit but reduced affective benefit"

6. **Cross-cultural variation**: If cultural context changes, then...
   - "If the mechanism depends on evolved priors to natural statistics, the benefit should vary with visual ecology"

Each prediction carries:
- **Derivation chain**: Which frameworks, which links, which operation
- **Confidence grading**: Confidence = confidence of weakest link in derivation
- **Testability assessment**: Experimental design, measures, expected effect size, feasibility
- **Novelty assessment**: Is this already known in the literature?
- **Independence assessment**: Does this prediction follow from multiple independent mechanisms?

### Step 6: Cross-Framework Convergence Assessment
**Input**: Predictions from multiple independent frameworks
**Operation**: Assess convergence and identify contradictions
**Output**: Convergence scores and discriminating predictions

**Convergence example** for "nature exposure reduces cortisol":
- **Predictive-processing**: Predicts reduction via spectral match → low prediction error
- **DMN/TPN dynamics**: Predicts reduction via low attention → DMN engagement → parasympathetic dominance
- **Embodied-cognition**: Predicts reduction via natural affordances → relaxed posture → vagal tone
- **Framework independence**: Predictive-processing and interoceptive-inference share theoretical core (HIGH dependence);
  DMN/TPN and embodied-cognition are more independent (MEDIUM dependence)
- **Effective independence score**: ~2.5 independent evidence paths (not 3 full paths)

**Contradiction detection**: When frameworks predict opposite effects, this is scientifically interesting:
- Flags either a boundary condition (mechanism applies only under specific circumstances)
- Or a scope limitation (mechanism doesn't apply to this population/context)
- Or a genuine theoretical conflict requiring empirical resolution
- Generates discriminating predictions that would confirm one framework and disconfirm another

### Step 7: Prediction Prioritization
**Input**: Set of generated predictions with metadata
**Operation**: Rank by expected scientific value
**Output**: Prioritized list

Ranking criteria:
1. **Convergence strength**: Multi-framework predictions > single-framework predictions
2. **Confidence**: How confident are we in the derivation chain?
3. **Novelty**: Predictions unknown in literature are higher value
4. **Testability**: Predictions with feasible experimental designs are ranked higher
5. **Specificity**: Precise quantitative predictions ranked higher than qualitative
6. **Falsifiability**: Predictions that could disconfirm major frameworks are highest priority

### Step 8: Prediction Ledger Entry
**Input**: Top-ranked predictions
**Operation**: Create DERIVED_HYPOTHESIS nodes in web of belief; create FindingMechanismLink edges
**Output**: New nodes and edges integrated into belief network

Each prediction becomes:
- A **derived_hypothesis** node (Tier 3) with justification tracing back to frameworks
- A **FindingMechanismLink** edge connecting finding to mechanism
- Pointers to prediction grammar operations that generated it
- Prediction-specific independence scores for convergence

## 4.2 Integration Points

### 4.2.1 Web of Belief Integration

FindingMechanismLink edges are stored in the web of belief graph:

```python
# In web_of_belief.py
class WebOfBelief:
    def add_finding_mechanism_link(
        self,
        link: FindingMechanismLink
    ) -> bool:
        """Add a finding-mechanism link to the belief network."""
        # Create edge in graph
        edge_id = link.link_id
        self.graph.add_edge(
            u_of_edge=link.template_id,
            v_of_edge=link.finding_id,
            edge_type=EdgeType.FINDING_MECHANISM_EXPLAINS,
            edge_data={
                "explanation_type": link.explanation_type.value,
                "confidence": link.overall_confidence,
                "mechanism_steps": [asdict(step) for step in link.mechanism_steps],
                "measure_alignment": link.measure_alignment,
                "converges_with": link.converges_with_frameworks,
            }
        )
        # Store full link object
        FINDING_MECHANISM_LINKS[edge_id] = link
        return True

    def get_mechanisms_for_finding(self, finding_id: str) -> List[FindingMechanismLink]:
        """Retrieve all mechanisms that explain a given finding."""
        return [
            FINDING_MECHANISM_LINKS[edge_id]
            for edge_id in self.incoming_edges(finding_id)
            if edge_id.startswith("FML-")
        ]

    def compute_finding_confidence(self, finding_id: str) -> float:
        """
        Compute overall confidence in a finding based on:
        - Direct empirical evidence (direct measurement)
        - Mechanistic explanation (how many frameworks explain it?)
        - Convergence (do independent mechanisms predict it?)
        """
        mechanisms = self.get_mechanisms_for_finding(finding_id)
        if not mechanisms:
            # Use empirical quality alone
            return self.nodes[finding_id].get("credence", 0.5)

        # Weight: direct evidence + mechanistic support
        direct_credence = self.nodes[finding_id].get("credence", 0.5)
        mechanism_confidences = [m.overall_confidence for m in mechanisms]
        mechanism_credence = sum(mechanism_confidences) / len(mechanism_confidences)

        # Combine: higher of the two, with boost if they converge
        convergence_boost = 0.1 if len(mechanisms) > 2 else 0.0
        combined = max(direct_credence, mechanism_credence) + convergence_boost
        return min(combined, 0.99)
```

### 4.2.2 Warrant Strength Integration

```python
# In warrant_strength.py
def compute_warrant_strength(
    finding_id: str,
    web: WebOfBelief
) -> WarrantStrengthScore:
    """
    Compute overall epistemic warrant for a finding.

    Components:
    1. Empirical quality (measurement, sample, design)
    2. Mechanistic support (how many frameworks explain it?)
    3. Independence (are supporting mechanisms independent?)
    4. Entrenchment (how entrenched is it in the web?)
    """

    # Get finding
    finding = web.nodes[finding_id]
    empirical_quality = finding.get("empirical_quality", 0.5)

    # Get mechanisms
    mechanisms = web.get_mechanisms_for_finding(finding_id)

    if not mechanisms:
        # Solitary finding: warrant = empirical quality + web entrenchment
        entrenchment = compute_entrenchment(finding_id, web)
        return WarrantStrengthScore(
            empirical_warrant=empirical_quality,
            mechanistic_warrant=0.0,
            entrenchment_warrant=entrenchment,
            overall=empirical_quality * 0.6 + entrenchment * 0.4
        )

    # Composite warrant: empirical + mechanistic + independence
    mechanism_confidences = [m.overall_confidence for m in mechanisms]
    independence_scores = [m.convergence_independence for m in mechanisms]

    mechanistic_warrant = (
        sum(mechanism_confidences) / len(mechanism_confidences) * 0.8 +
        (sum([ind_to_score(i) for i in independence_scores]) / len(independence_scores)) * 0.2
    )

    entrenchment = compute_entrenchment(finding_id, web)

    # Multi-mechanism convergence gives 10% boost
    convergence_boost = 0.1 if len(mechanisms) > 2 else 0.0

    overall = (
        empirical_quality * 0.4 +
        mechanistic_warrant * 0.4 +
        entrenchment * 0.2 +
        convergence_boost
    )

    return WarrantStrengthScore(
        empirical_warrant=empirical_quality,
        mechanistic_warrant=mechanistic_warrant,
        entrenchment_warrant=entrenchment,
        overall=min(overall, 0.99)
    )


def ind_to_score(independence: str) -> float:
    """Convert independence string to numeric score."""
    return {"low": 0.3, "medium": 0.65, "high": 1.0}.get(independence, 0.5)
```

# PART VII: EPISTEMIC NORMS AND PANEL REVIEW

## 7.1 Quality Standards

Any FindingMechanismLink must meet:

1. **Mechanism explicitness**: Every step in the chain must be named; no vague handwaving
2. **Evidence attribution**: Every claim has a citation or explicit "unobserved"
3. **Maturity honesty**: Intermediate steps marked how-possibly/how-plausibly must not be hidden
4. **Measurement alignment**: Clear statement of whether mechanism's predictions are actually measured
5. **Scope specification**: Explicit conditions under which the mechanism applies
6. **Alternative consideration**: Other mechanisms evaluated and explicitly rejected

## 7.2 Panelist Review Points

Experts reviewing CMR implementations should focus on:

**Lindley Darden** (Mechanism Discovery):
- Are mechanism chains coherent and productive?
- Do steps follow Machamer et al. entity-activity-change structure?
- Are maturity tags honest?

**James Woodward** (Interventionist Causation):
- Are w-question operations correctly formalized?
- Do predictions follow from mechanism structure?
- Are type-level vs. token-level predictions distinguished?

**Carl Craver** (Multilevel Mechanistic Explanation):
- Are cross-level bridges explicit and quality-graded?
- Do level transitions respect multilevel mechanistic principles?
- Are circuit/cellular/molecular links appropriate?

**Lisa Feldman Barrett** (Interoceptive Inference):
- Is the role of prediction error in affective/physiological outcomes captured?
- Are allostatic regulation pathways included?
