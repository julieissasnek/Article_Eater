## Key Theoretical Points Developed This Session

### 1. The Explicit–Implicit Bridge Mechanism (fully articulated)
The four-step bridge:
1. Activity selection is *explicit* (deliberate, prefrontal, goal-directed)
2. Once set, the activity frame reconfigures the *affordance ecology* (which features are salient, which affordances are perceived)
3. This reconfiguration is largely *implicit* (automatic, task-positive network, attentional filtering)
4. Therefore the *effective stimulus* over which PE-based processing operates changes → Goldilocks optimum shifts

This is the core theoretical contribution: explicit processing *gates* implicit processing through activity-frame-mediated affordance reconfiguration.

### 2. Activity Space as Meta-Framework
- Only Tier 1 framework operating at the *logical* level (goal-subgoal structure)
- Provides *moderating* predictions: all other frameworks' inverted-Us are conditional on activity frame
- Structurally complementary to PP, Berlyne, ART, Biophilia, SRT — doesn't compete, it sets boundary conditions

### 3. Cognitive Congeniality as Distinct Dimension
- Not reducible to physical ergonomic optimization
- Measurable via behavioral metrics (speed-accuracy, interruption recovery, error cost)
- Two physically identical spaces can differ in congeniality (mise-en-place argument)
- Connects to Kirsh's broader body of work (1995, 1996, 2019)

### 4. Template Specifications (T_AS_001–T_AS_004)
All four templates from prior session now have full specification text:
- T_AS_001: Cognitive Congeniality Modulation (congeniality × stimulus → performance)
- T_AS_002: Epistemic Bubble Gating (same feature → different PE depending on bubble)
- T_AS_003: Multi-Activity Interference (overlapping bubbles → degraded optimization)
- T_AS_004: Cognitive Congeniality ≠ Physical Optimization (independent dimensions)
