# Librarian Workflow (Human-in-the-Loop)

The Librarian tab is where you ingest new papers and review raw Seven-Panel
extractions before they enter the rule engine.

**Core responsibilities**

- Upload or paste paper text and (optionally) the abstract.
- Trigger extraction with the Librarian tools.
- Spot-check Seven-Panel items for obvious hallucinations or mis-parses.
- Mark items as accepted / rejected before they are used downstream.

See `GUI_Verbiage_Package.docx` for the student-facing copy used in the tooltips
and modals for this tab.
