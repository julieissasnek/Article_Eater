# Admin Control Room

The Admin Control Room is for advanced users (TAs, researchers, instructors).

- Use the **Prompts** tab to edit LLM prompt templates in `/prompts`.
- Use the **Confidence** tab to tune weights in `confidence_config.yml`.
- Changes here affect extraction quality and calibration globally.

Only users who understand the experimental design and the underlying prompts
should change these settings. Student help text and visual guidelines are
documented in `ARTICLE_EATER_GUI_STYLE_GUIDE.md` and `GUI_Verbiage_Package.docx`.
