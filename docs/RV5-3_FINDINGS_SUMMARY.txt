2. STATISTICAL FIELD GAPS (EMPIRICAL CLAIMS)
   Status: CRITICAL
   ┌─────────────────────────────────────────────────────┐
   │ Findings with effect_size but NO p_value:          │
   │   1,688 (5.1% of corpus) ✗                         │
   │                                                      │
   │ Findings with p_value but NO effect_size:          │
   │   1,506 (4.6% of corpus) ✗                         │
   │                                                      │
   │ Findings with NO sample_size:                       │
   │   ~27,000 (82% of corpus) ✗                        │
   │                                                      │
   │ Empirical findings with ALL stats (p + ES + N):    │
   │   ~2,500 (8% of empirical claims) ✗✗              │
   └─────────────────────────────────────────────────────┘

   Root Cause: Extraction prompt doesn't enforce "extract stats
               from Results section." Gemini reads Methods
               (where effect sizes mentioned) but misses Results.

   Impact: Meta-analysis impossible for 92% of empirical claims.
           Confidence weighting broken.

           Real empirical evidence base is ~30% smaller than stated.

1. Direction field contamination (17.3%)
2. Statistical field gaps (62–92% incomplete for empirical)
3. No article-type discrimination (18% over-extraction)

These are FIXABLE. With Sprint 1–2 work (21–29 hours total), the
pipeline could reach 6.5/10 (approaching production-ready).

Current recommendation: DO NOT use for model training, meta-analysis,
or downstream inference without addressing Critical issues first.

filtering of problematic findings).
