## CRITERION #3: TEMPLATE COVERAGE ANALYSIS

The formal T1.5 qualification requires that a candidate theory **reduces to specific mechanism templates with ≥60% coverage**. This document provides the detailed analysis of why all four candidates fail this criterion.

### Coverage Threshold Justification

The 60% threshold ensures that:
1. A T1.5 theory is not a fringe specialization but covers the majority of phenomena in its domain
2. The theory has sufficient empirical grounding (62% of 208 = ~125 templates must instantiate the theory's mechanisms)
3. The theory's T1 parent framework(s) cannot fully explain all instantiations
4. The theory's organizational principle cuts across existing template organization

**Why 60% not 40% or 80%?**
- 40% is too permissive; it would justify theories that cover only a minority of phenomena
- 80% is too restrictive; it would require near-complete theoretical saturation, leaving little room for T1 frameworks
- 60% is the Pareto principle (80/20 applied inversely): if 60% of templates instantiate a theory, that theory explains the majority systematic variance

## DETAILED COVERAGE BREAKDOWN BY CANDIDATE

### CANDIDATE 1: EPISODIC MEMORY THEORY

**Coverage**: 7 templates (3.4%)
**Needed for T1.5**: 125 templates (60% of 208)
**Shortfall**: 118 templates (-56.6 pp)

#### Templates Currently Mapped to Episodic Memory Theory

1. **ED_HIPPOCAMPAL_ENCODING_001**
   - Framework parents: MS, SN
   - Mechanism: PPA → EC → DG → CA1 relational binding
   - Why relevant: Episodic memory depends on hippocampal encoding of what-where-when
   - Issue: This mechanism is explained by MS (Memory Systems), not *reduced to* Episodic Memory Theory

2. **ED_SCHEMA_ENCODING_001**
   - Framework parents: MS
   - Mechanism: Schema abstraction from episodic traces via systems consolidation
   - Why relevant: Schema extraction is central to episodic→semantic transformation
   - Issue: Schema extraction is a Memory Systems process, not unique to episodic memory

3. **ED_SYSTEMS_CONSOLIDATION_001**
   - Framework parents: MS
   - Mechanism: Hippocampal→cortical consolidation over weeks to months
   - Why relevant: Episodic consolidation into semantic memory is Tulving's core observation
   - Issue: This is the MS framework operating; consolidation is independent of episodic phenomenology

4. **ED_RECONSOLIDATION_001**
   - Framework parents: MS
   - Mechanism: Memory updating when environmental re-exposure occurs
   - Why relevant: Episodic memories are updated when context revisited
   - Issue: Reconsolidation is a MS process; episodic specificity is secondary

5. **THRESHOLD_EPISODIC_BOUNDARY_001**
   - Framework parents: DT, DP (implicitly)
   - Mechanism: Event boundary detection as shift in predictive context
   - Why relevant: Episodes are bounded by event transitions
   - Issue: Event segmentation is a PP/DT mechanism; episodic memory simply uses these boundaries

6. **BRECVEMA_MEMORY_005**
   - Framework parents: PP, NM, SN
   - Mechanism: Emotional memory as brainstem-rooted expectation violation
   - Why relevant: Episodic memories have emotional salience
   - Issue: This is explained by NM (emotion) + PP (expectation); episodic aspect is secondary

7. **SN_CONTEXT_MEMORY_002**
   - Framework parents: SN
   - Mechanism: Context representation in spatial navigation system
   - Why relevant: Spatial context is bound to episodic memory
   - Issue: This is the SN framework; context binding is about spatial cognition, not episodic memory

#### Why Coverage Is Inadequate

**Structural reason**: The system organizes templates around *mechanistic processes* (encoding, consolidation, reconsolidation, spatial binding), not around *phenomenological categories* (episodic vs. semantic). Episodic Memory Theory describes *what kind of memory* something is ("I remember the specific day I visited the museum"), not *how* the memory is implemented.

**Analogy**: Imagine a library organized by *book binding technique* (hardcover, paperback, digital) rather than by *genre* (fiction, non-fiction, poetry). Now you ask: "Don't you have a non-fiction T1.5 theory? Your templates show only 7 books labeled 'non-fiction.'" The answer is: non-fiction is a *phenomenological category*, not a mechanistic organizational principle. The library's actual organization (binding technique) cross-cuts this categorization.

Similarly, episodic vs. semantic is a *phenomenological distinction* ("What is it like to remember?"), not a mechanistic distinction. The system's mechanistic frameworks (MS, SN, PP) can produce both episodic and semantic phenomena depending on context and consolidation dynamics.

#### What Would Be Needed to Reach 60%?

To qualify Episodic Memory Theory as T1.5, the system would need:
- ~125 templates instantiating episodic-specific mechanisms
- This would require templates like:
  - "Hippocampal encoding of personal experience" (vs. generic facts) — but this is *where* episodic encoding happens, explained by MS/PPA
  - "Temporal specificity in episodic vs. semantic memory" — but temporal binding is *how* consolidation works, explained by systems consolidation
  - "Autobiographical context in memory retrieval" — but context effects are *explained by* DG pattern completion and CA1 context binding, which are MS processes
  - "Reconsolidation specificity to episodic memories" — but reconsolidation applies to all memory types; episodic is not special

**Bottom line**: To reach 60% would require either: (a) relabeling 120+ memory/encoding/consolidation templates as "episodic," which would be arbitrary, or (b) discovering new mechanistic principles specific to episodic memory, which would challenge the MS framework's universality.

### CANDIDATE 2: BERLYNE'S AROUSAL THEORY

**Coverage**: 2 templates (1.0%)
**Needed for T1.5**: 123 templates (60% of 208)
**Shortfall**: 121 templates (-59.0 pp)

#### Templates Currently Mapped to Berlyne Arousal

1. **PROCESSING_STYLE_MODULATION_001**
   - Framework parents: NM, DT
   - Mechanism: Arousal level → shift from analytic to holistic processing
   - Berlyne relevance: Arousal modulates complexity perception and hedonic response
   - Issue: This is NM (arousal mediation) and DT (processing style trade-off); Berlyne is not the organizing principle

2. **CROSS_ENVIRONMENTAL_PROCESSING_STYLE_001**
   - Framework parents: NM, DT
   - Mechanism: Same arousal-processing shift across visual, auditory, spatial domains
   - Berlyne relevance: Arousal effects should generalize across sensory modalities
   - Issue: Cross-domain generalization is about DT/NM, not specifically about Berlyne's complexity-preference relationship

#### Why Coverage Is So Inadequate

**Integration into T1**: Berlyne's inverted-U (complexity/novelty → arousal → hedonic value) has been *reinterpreted* through the Goldilocks principle in Predictive Processing. The T1.0 Theory Tier Architecture document states:

> "Moderate prediction errors that are resolvable are rewarding (dopaminergic reward from successful model updating); prediction errors too large to resolve are aversive (noradrenergic hyperarousal); prediction errors too small are boring (insufficient dopaminergic activation)." — Section 3.5

This is Berlyne's inverted-U *reframed as* prediction error dynamics. The mechanism is now:
- **Low complexity** → low prediction error → insufficient dopamine activation → boring
- **Moderate complexity** → moderate prediction error → resolvable error → dopamine reward → optimal
- **High complexity** → large prediction error → unresolvable error → noradrenergic hyperarousal → anxiety

**What Berlyne provided**: Observation of inverted-U phenomenon and naming of "arousal" as the mediating variable.

**What T1 frameworks provide**: Mechanistic explanation via PP (prediction error) and NM (noradrenergic/dopaminergic response).

**Why Berlyne_Arousal has only 2 templates**: Because the system's organizing principle is *mechanisms* (PP, NM, DT), not *Berlyne's theoretical vocabulary* (arousal, hedonic value, collative variables). The two templates that mention Berlyne_Arousal are about arousal modulation (NM) and processing style shifts (DT), not about the complexity-preference relationship per se.

#### What Berlyne Would Need for T1.5

Templates would need to address:
- Visual complexity → hedonic preference in architecture (but this is covered under PP fractal analysis, not Berlyne)
- Acoustic complexity → arousal → emotional response (covered under NM dopamine/noradrenaline, not Berlyne)
- Stimulus ambiguity and complexity perception (covered under PP prediction error, not Berlyne)
- Collative variables (novelty, surprise, incongruity, complexity) as independent factors (but these all reduce to prediction error magnitude under PP)

**Bottom line**: Berlyne's theory was a valuable step in understanding aesthetic preference (1971 observation), but its explanatory mechanisms have been superseded by PP and NM. Reviving it as T1.5 would mean *undoing* the theoretical unification that PP/NM provide. The current organization is more parsimonious.

### CANDIDATE 3: PREDICTIVE CODING OF MUSIC

**Coverage**: 2 templates (1.0%)
**Needed for T1.5**: 123 templates (60% of 208)
**Shortfall**: 121 templates (-59.0 pp)

#### Templates Currently Mapped to Predictive Coding of Music

1. **NEURAL_MUSIC_EMOTION_ARCH_001**
   - Framework parents: NM, PP
   - Mechanism: Musical structure (harmony, melody, rhythm) → expectation → emotion
   - Music-specificity: Not particularly music-specific; mechanism applies to any temporal sequence
   - Issue: This is PP (expectation) + NM (emotional response); music is one domain

2. **BRECVEMA_EXPECTANCY_004**
   - Framework parents: PP, NM
   - Mechanism: Brainstem-rooted expectation violation → emotional arousal
   - Music-specificity: The template is about expectation in general, not music specifically
   - Issue: BRECVEMA is a general emotional framework; music is one application

#### Why Coverage Is Inadequate

**Music is peripheral to neuroarchitecture**: The Article Eater system's focus is on how *built environments* affect cognition and affect. Music's role in built environments is:
- **Ambient**: Background music in offices, retail, hospitality (secondary design consideration)
- **Event-based**: Concerts, performances in spaces (architectural venue, not architecture per se)
- **Not constitutive**: Music is not a primary *feature* of architectural experience like light, space, material, acoustic isolation, temperature

Compare this to:
- **Visual properties** (complexity, fractal dimension, color, light): primary features of every architectural space (49 templates)
- **Spatial properties** (navigation, cognitive mapping, proportion): primary features of every building (18 templates)
- **Acoustic properties** (environmental noise, reverberation, privacy): primary features (but underdeveloped, 3-5 templates)
- **Material/tactile properties** (texture, thermal, aging): primary features (8-10 templates)

**Music occupies a niche**: NEURAL_MUSIC_EMOTION_ARCH_001 and BRECVEMA_EXPECTANCY_004 address music, but they're organized under NM and PP, not under a dedicated music theory.

**Why only 2 templates?** Because music is *one instantiation* of Predictive Coding in the auditory domain, not a domain-organizing principle. Predictive Coding applies equally to:
- Visual scenes (49 PP templates)
- Acoustic scenes (3-5 auditory templates)
- Temporal sequences (rhythm, melody, beat — embedded in auditory or motor templates)

#### What Predictive Coding of Music Would Need for T1.5

Would need ~120+ templates addressing:
- Harmonic expectation violations across different musical cultures
- Rhythmic synchrony and body entrainment
- Melodic contour prediction
- Dissonance as prediction error
- Tonal system learning (schema formation for music)
- Music's role in attention, memory, emotional regulation in spaces
- Acoustic branding and music-architecture synergy
- Background music effects on cognitive load

**But why create these as "Music theory" rather than as "Auditory PP templates"?** Because music shares PP mechanisms with language (prosody), non-musical sounds (traffic, birds), and other temporal sequences. Creating a separate Music theory would fragment Predictive Processing without gaining explanatory power.

**Bottom line**: Music is important for some neuroarchitecture applications (hospitality, wellness centers, performance venues), but it's neither a primary architectural domain nor a mechanistically novel framework. It belongs in Tier 2 as an application domain within Predictive Processing.

### CANDIDATE 4: AUDITORY SCENE ANALYSIS (BREGMAN)

**Coverage**: 3 templates (1.4%)
**Needed for T1.5**: 122 templates (60% of 208)
**Shortfall**: 119 templates (-58.6 pp)

#### Templates Currently Mapped to Auditory Scene Analysis

1. **AUD_SCENE_ANALYSIS_001**
   - Framework parents: MSI, PP
   - Mechanism: Stream segregation capacity limits (3-5 concurrent sources) → cognitive load → stress
   - Bregman-specificity: Core ASA mechanism; explicitly cites Bregman (1990)
   - Status: Well-developed template (mechanism chain with step-by-step justification)

2. **AUDITORY_FRACTAL_SCALING_001**
   - Framework parents: PP
   - Mechanism: Acoustic fractal dimension optimization for auditory preference
   - Bregman-specificity: Related to ASA via analogy (fractal structure aids stream segregation?)
   - Status: Partially relevant; primarily about fractal analysis, not stream segregation

3. **AUD_REVERBERATION_SPACE_003**
   - Framework parents: MSI, EC
   - Mechanism: Reverberation characteristics → spatial impression → stream coherence
   - Bregman-specificity: Reverberation is acoustic cue for stream grouping
   - Status: Moderately relevant; addresses one ASA cue (spatial coherence)

#### Why Coverage Is Inadequate but Less Damning

Unlike the first three candidates, Auditory Scene Analysis has a real mechanistic claim:

**ASA's core claim**: The auditory system has inherent capacity limits for simultaneously segregating and monitoring acoustic streams. The limit (~3-5 sources for complex scenes) is *not explained* by:
- Predictive Processing alone (PP predicts expectation violations but doesn't predict segregation capacity limits)
- Multisensory Integration alone (MSI explains cross-modal binding but not intra-auditory segregation)
- Neuromodulation alone (NM explains arousal modulation but not the capacity limit itself)

**The capacity limit is a neurobiological fact** about auditory system design. The question is: should this fact be organized under a T1.5 theory called "Auditory Scene Analysis," or should it remain embedded in MSI/PP frameworks?

#### Why Coverage Is Still Inadequate

The 3 templates address ASA, but there are only 3-5 auditory domain templates total out of 208. This means:

1. **Auditory domain is underdeveloped** (1.4-2.4% of templates vs. 24% for visual PP)
2. **ASA is not the dominant organizing principle** in auditory domain
3. **Other auditory phenomena** (reverberation, acoustic masking, speech intelligibility, noise stress) are scattered across MSI, NM, IC frameworks

#### What Auditory Scene Analysis Would Need for T1.5

Would require systematic development of auditory domain (15-20 templates minimum):

**Tier 1: Core ASA phenomena**
- Stream segregation and source identification (1 template — exists: AUD_SCENE_ANALYSIS_001)
- Spectral grouping cues (pitch, timbre, spectral envelope) — needs 2 templates
- Temporal grouping cues (synchrony, onset time) — needs 1 template
- Spatial grouping cues (localization, distance) — needs 1 template

**Tier 2: Architectural implications of ASA**
- Open-plan office acoustic complexity and cognition — needs 2 templates
- Hospital soundscapes and stream segregation stress — needs 1 template
- Quiet/enclosed spaces as ASA capacity relief — needs 1 template
- Sound masking and ASA interference — needs 1 template

**Tier 3: Stress pathways from acoustic complexity**
- Stream segregation load → cognitive depletion → cortisol → allostatic load — needs 2 templates
- Attention allocation with competing streams — needs 1 template
- Sleep disruption from acoustic complexity — needs 1 template

**Tier 4: Individual/contextual modulation**
- Age effects on stream segregation capacity — needs 1 template
- Expertise effects (musicians, linguists) — needs 1 template
- Stress/anxiety modulation of ASA capacity — needs 1 template

This gives ~18 templates total (from 3 currently), reaching 8.6% coverage. Still short of 60%, but a realistic development path.

#### Why Auditory Scene Analysis Is the Strongest Candidate

1. **Mechanistically justified**: Stream segregation capacity limits are *not fully explained* by existing T1 frameworks
2. **Architecturally relevant**: Acoustic complexity is a primary design parameter for neuroarchitecture
3. **Domain gaps are real**: Auditory domain is ~5-7% of templates vs. visual at ~24%
4. **Organized alternative**: Creating Auditory Scene Analysis as T1.5 would provide a focal organizing principle for acoustic design

#### Why Even ASA Falls Short for Immediate T1.5 Qualification

1. **Current coverage (1.4%) is far below 60%**: Would require 119 additional templates
2. **Auditory domain would need to become 60% of total system** for ASA to reach 60% coverage
3. **This is unrealistic** given neuroarchitecture's visual and spatial focus
4. **More feasible**: Expand auditory to 15-20 templates (8-10% of total), then re-assess whether ASA merits T1.5 or remains a prominent Tier 2 organizing schema

## CONCLUSION

All four candidates fail the 60% coverage threshold by massive margins (56-59 pp). The gaps are too large to be overcome by incremental template development. The underlying issue is **theoretical integration**: all four theories' core claims are already explained by existing T1 frameworks.

**Auditory Scene Analysis** is the only candidate with mechanistically justified content (stream segregation capacity limits), and the only one with a realistic development path. Even so, it would require substantial investment (15-20 new auditory templates) to reach even 10% coverage, with full T1.5 qualification remaining unrealistic given neuroarchitecture's visual and spatial focus.

**The system is not missing T1 frameworks or T1.5 theories.** Rather, it has: (1) substantial T1 frameworks that are complete, (2) uneven domain coverage (visual dominating, auditory weak), and (3) well-articulated Tier 2 phenomenological schemas that organize the domain-specific instantiations of T1.

The appropriate strategic response is **domain development**, not theory promotion.
