## 1.2 Panel Critiques

### LINDLEY DARDEN

**Critique 1 — Templates need maturity tags.** Mechanism discovery proceeds through stages: *how-possibly* (speculative), *how-plausibly* (supported conjecture), *how-actually* (confirmed). The template "nature view → 1/f spectral match → low prediction error → reduced metabolic cost" mixes maturity levels: spectral statistics of natural scenes and predictive coding of visual input are how-actually; prediction error magnitude → metabolic cost is how-plausibly. Predictions derived from a template should carry confidence reflecting the weakest maturity level.

**Critique 2 — Missing backward reasoning from anomalies.** The pipeline starts with findings and traces mechanisms forward. But productive scientific reasoning often goes backward from surprising findings that don't fit existing templates, asking "What mechanism could produce this?" This is abductive reasoning generating new template *candidates*, not deductive reasoning applying existing templates. The system needs a template *construction* mode triggered by anomalous findings.

**Critique 3 — Underspecified composition interference.** The COMBINE_MECHANISMS operation doesn't check for interference effects. Two mechanisms independently producing cortisol reduction might not produce additive effects — ceiling effects, compensatory feedback, and pathway interactions are common. Combination operations need checks for known interaction patterns.

### DEDRE GENTNER

**Critique 4 — Templates need two-level representation.** Templates should be represented at both a **surface level** (specific entities, brain regions, measures) and a **structural level** (relational roles, higher-order organizing principles). The predictive processing complexity-preference template isn't just "complexity → prediction error → preference" — it's organized by a higher-order optimization principle (minimize long-term prediction error, which means moderate short-term error is preferred). This higher-order structure is what enables transfer across sensory modalities. Retrieval should operate primarily on structural level.

**Critique 5 — Track alignable differences.** When a template partially matches a finding (some elements align, others don't), the non-aligning elements generate candidate inferences about unobserved variables or undetected mechanisms. These are often the most productive inferences from analogy.

### JAMES WOODWARD

**Critique 6 — Distinguish type-level from token-level predictions.** "High-anxiety patients should benefit more from nature views" is type-level (requires population sampling). "This patient, with this anxiety level, should show this cortisol reduction" is token-level (testable in individual cases). Both are legitimate but have different testing requirements and clinical implications.

**Critique 7 — Distinguish total causes from contributing causes.** If the nature-view effect operates through multiple independent pathways (spectral match AND biophilic priming AND spatial openness), blocking one pathway blocks the *contribution* of that pathway, not the total effect. Predictions must specify which they're about.

**Critique 8 — Track modularity violations.** Biological systems often violate the assumption that you can intervene on one variable without disrupting others. Pharmacological intervention on noradrenergic arousal also affects serotonergic, cholinergic, and immune systems. Predictions requiring modular interventions on coupled systems should be flagged.

### CARL CRAVER

**Critique 9 — Add level tags and bridging quality grades.** Every link in every template should carry a level tag: {ecological, computational, circuit, cellular, molecular}. Cross-level links need bridging quality grades (how well-established is the bridge?). Some bridges are rock-solid (dopamine in nucleus accumbens → reward signal). Others are speculative (DMN activation → "self-referential processing").

**Critique 10 — Organize template library by level.** Don't encode "environment → cortisol" as a single template. Encode it as separate bridging templates: ecological→computational, computational→circuit, circuit→molecular. Composing bridges into a complete trace is itself a reasoning operation that should be explicit and auditable.

### NANCY NERSESSIAN

**Critique 11 — Add a simulation step.** Scientists reason with *mental models* — dynamic, runnable simulations — not static templates. After formal prediction generation, the system should run the composed mechanism dynamically to check for emergent behaviors, oscillations, feedback loops, and tipping points that static traces miss. Templates should be runnable, not just structural.

**Critique 12 — Support thought experiments.** Beyond formal prediction generation operations, the system should support deliberate counterfactual manipulation of composed mechanisms to discover unexpected emergent effects.

### KEVIN HOLYOAK

**Critique 13 — Parameterize search by reasoning goal.** Framework Matching shouldn't be a single retrieval operation. Different goals (explain, predict, design experiment, find boundary conditions, identify cultural variation) should activate different template features. The same finding should match different templates depending on the pragmatic context.

**Critique 14 — Make independence matrix prediction-specific.** Predictive processing and interoceptive inference are heavily dependent for predictions about affective experience but quite independent for predictions about visual processing. Independence scores should be computed relative to the specific prediction, not assigned as fixed framework-pair constants.

### LISA FELDMAN BARRETT

**Critique 15 — Add composition failure detection.** When two templates from different frameworks can't be composed because they make incompatible assumptions about the same variable, that's not an error — it's a discovery. The system should identify where the incompatibility lies, characterize the conflict, generate discriminating predictions that would be confirmed by one framework and disconfirmed by the other, and flag these as high-priority empirical questions. This is how new theories get born.

**Critique 16 — Include allostatic regulation pathways.** The brain doesn't just predict the body's current state; it anticipates future needs and prepares resources in advance (Sterling, 2012). Environments that allow efficient anticipatory metabolic preparation should be more restorative than environments requiring reactive regulation. This is a different pathway from pure prediction error minimization.

### PAT LANGLEY

**Critique 17 — Build template learning from confirmed predictions.** When a prediction generated by composing two templates is empirically confirmed, the composition should be consolidated into a new template for future reasoning. Without template learning, the system can't grow beyond its initial knowledge engineering.

**Critique 18 — Start with ~20 templates, iterate.** Get the full pipeline working end-to-end on a focused domain before attempting comprehensive coverage. The biggest mistake in computational discovery systems is trying to be comprehensive before being correct.

### ALISON GOPNIK

**Critique 19 — Design for framework revision.** Don't hard-code the 8 Tier 1 frameworks. Make the framework layer dynamic — frameworks can be added, modified, or deprecated based on their track record. The system should represent competing framework candidates alongside existing ones and compare predictive performance.

**Critique 20 — Plan for schema learning.** Template learning (Langley's point) is a step, but full schema learning would allow the system to learn the *space of possible templates* — not just individual mechanism pathways but the structural grammar that generates them.

## 2.1 Architecture Overview

```
[Level 1] Extraction: Papers → Claims + Relations
[Level 2] Web: Claims + Relations → Coherent belief network
[Level 3] BN: Belief network → Causal graph with parameters
[Level 4] CMR: Causal graph + Framework templates → Novel predictions  ← THIS SPEC
```

CMR sits on top of the existing Article Eater architecture. It reads from the web of belief and writes DERIVED_HYPOTHESIS nodes back into it.

## 2.2 The Revised 8-Step Pipeline

*(Original 6 steps + 2 new steps from panel recommendations)*

### Step 1: Causal Decomposition
*(Bechtel & Richardson, 1993/2010 — decomposition strategy)*

**Input**: An extracted finding (Tier 3 claim).
**Operation**: Decompose into component causal variables: stimulus features, mediator candidates, outcome measures, population characteristics, contextual factors.
**Output**: A structured variable set with role labels.

**Variable ontology** for cognitive neuroarchitecture:
- Environmental features: spatial (layout, volume, ceiling height, enclosure), surface (material, texture, color), ambient (light, sound, temperature, air quality), content (biophilic elements, complexity, order, novelty)
- Perceptual processes: visual processing, auditory processing, proprioceptive/vestibular, olfactory, multisensory integration
- Neural systems: cortical regions, subcortical structures, neuromodulatory pathways, autonomic nervous system
- Physiological responses: HPA axis (cortisol), autonomic (heart rate, GSR, blood pressure), immune markers
- Psychological states: affect (valence, arousal), cognition (attention, working memory, executive function), motivation (approach/avoidance)
- Behavioral outcomes: wayfinding, social behavior, task performance, exploration, dwelling time
- Wellbeing measures: self-report, allostatic load, restoration, satisfaction

### Step 2: Framework Matching
*(Darden, 2002 — schema instantiation; incorporating R4, R13)*

**Input**: Structured variable set from Step 1 + **reasoning goal** (R13: explain / predict / design experiment / find boundary conditions / identify cultural variation).
**Operation**: Search the Tier 1 framework library for frameworks whose scope declarations cover the decomposed variables. Search at STRUCTURAL level first (R4), then verify at surface level.
**Output**: A ranked list of matched frameworks with match quality scores.

**Changes from V1.0**:
- Matching is parameterized by reasoning goal (R13). Goal "explain" retrieves templates with complete causal chains. Goal "predict" retrieves templates with well-characterized intervention points. Goal "find boundary conditions" retrieves templates with explicit scope conditions and known limitations.
- Retrieval operates on structural-level representations (R4) — matching relational roles and organizing principles, not surface entities. This enables cross-domain transfer (e.g., visual complexity template retrieved for auditory complexity finding via shared optimization structure).

**Variable-to-framework index** (examples):
| Variable | Primary Frameworks | Secondary Frameworks |
|---|---|---|
| cortisol | Neuromodulatory (HPA axis) | Interoception, Memory Systems |
| prediction error | Predictive Processing | Neuromodulatory (precision weighting) |
| cognitive map quality | Spatial Navigation | Embodied Cognition |
| DMN engagement | DMN/TPN Dynamics | Memory Systems, Predictive Processing |
| affect valence | Interoception | Neuromodulatory (dopamine, opioid) |
| affordance perception | Embodied Cognition | Spatial Navigation |

### Step 3: Mechanism Tracing
*(Darden & Craver, 2002 — forward chaining; incorporating R1, R3, R9)*

**Input**: Matched frameworks from Step 2 + relevant templates from library.
**Operation**: For each matched framework, trace the causal mechanism from stimulus through intermediaries to outcome, using mechanistic templates. Each link specifies entity, activity, produced change, level, and maturity.
**Output**: One or more mechanism traces, each a sequence of typed, leveled, maturity-tagged links.

**Template link structure** (revised with R1 and R9):
```yaml
link:
  from_entity: "visual_cortex_V1"
  activity: "efficient_coding_of_1/f_spectrum"
  to_entity: "prediction_error_signal"
  change_produced: "reduced prediction error magnitude"
  level: "circuit"                    # R9: ecological/computational/circuit/cellular/molecular
  bridging_to: "computational"        # R9: if cross-level, what level does it bridge to?
  bridging_quality: "HIGH"            # R9: how well-established is this bridge?
  maturity: "how-actually"            # R1: how-possibly/how-plausibly/how-actually
  evidence_base: "Rao & Ballard 1999; Olshausen & Field 1996"
  parameter_range:
    effect_magnitude: "40-60% reduction in prediction error for natural vs scrambled"
    temporal_dynamics: "onset 50-150ms post-stimulus"
    dose_response: "approximately logarithmic with spatial frequency match"
  scope_conditions:
    requires: "intact early visual processing"
    uncertain_for: "very low contrast stimuli, peripheral vision"
  known_interactions:               # R3: composition interference check
    - "attention_modulation: top-down attention can override efficient coding"
    - "adaptation: prolonged exposure reduces the efficient coding advantage"
```

**Composition rules** (revised with R3):
When composing two template modules:
1. Check for **shared intermediate variables** — do the modules both affect the same variable? If so, check interaction type: additive, multiplicative, ceiling, compensatory.
2. Check for **known interference patterns** — does the literature report interactions between these pathways? (e.g., serotonergic and dopaminergic modulation of HPA axis are not independent — they interact via raphe-VTA projections).
3. If interaction type is unknown, flag the composition as **interaction-uncertain** and the resulting prediction as requiring empirical verification of additivity.

### Step 4: Prediction Generation via Interventionist Reasoning
*(Woodward, 2003; incorporating R6, R7, R8)*

**Input**: Completed mechanism trace(s) from Step 3.
**Operation**: Apply prediction generation grammar — formal operations that interrogate each intervention point in the trace.
**Output**: A set of predictions, each tagged with derivation chain, confidence, prediction level, and cause type.

**Revised Prediction Generation Grammar** (10 operations, expanded from 8):

| # | Operation | Input | Output | Basis |
|---|---|---|---|---|
| 1 | SUBSTITUTE_CAUSE | Trace + alternative cause with same structural properties | Prediction: alternative cause → same effect | Woodward interventionism |
| 2 | VARY_MODERATOR | Trace + identified moderator variable | Prediction: moderator variation → effect variation | Moderation logic |
| 3 | BLOCK_PATHWAY | Trace + identified mediator | Prediction: blocking mediator → reduced/eliminated effect | Woodward interventionism |
| 4 | VARY_TEMPORAL_CONTEXT | Trace + temporal dynamics | Prediction: temporal manipulation → effect variation | Template temporal parameters |
| 5 | VARY_INDIVIDUAL | Trace + individual difference variable | Prediction: individual variation → effect variation | Individual differences |
| 6 | CROSS_CULTURAL | Trace + culturally variable parameter | Prediction: cultural variation → effect variation | Generative model calibration |
| 7 | COMBINE_MECHANISMS | Two traces with shared intermediate | Prediction: combined manipulation → combined effect (with R3 interference check) | Compositional logic |
| 8 | DOSE_RESPONSE | Trace + parameter ranges | Prediction: dose variation → response curve shape | Quantitative constraints |
| 9 | DISTINGUISH_TOTAL_VS_CONTRIBUTING | Multi-pathway trace | Prediction set: total effect vs. pathway-specific contributions (R7) | Woodward contributing cause |
| 10 | TYPE_VS_TOKEN | Any prediction | Tagged duplicate: type-level version + token-level version with required specifics (R6) | Woodward type/token |

**Prediction output structure** (revised):
```yaml
prediction:
  id: "PRED_2026_001"
  statement: "Artificial scenes with 1/f spectral statistics should produce cortisol reduction comparable to natural scenes"
  derivation_chain:
    - framework: PREDICTIVE_PROCESSING
    - template: PP_SPECTRAL_MATCH_001
    - operation: SUBSTITUTE_CAUSE
    - reasoning: "If mechanism is spectral match (not natureness), then any stimulus with 1/f statistics should activate same pathway"
  confidence:
    overall: 0.65
    weakest_link: "step3: prediction error → metabolic cost (how-plausibly, not how-actually)"
    weakest_link_maturity: "how-plausibly"          # R1
  prediction_level: "type"                           # R6: type or token
  cause_type: "contributing"                         # R7: total or contributing
  modularity_concerns:                               # R8
    - "spectral statistics cannot be varied independently of other visual properties (color, contrast, semantic content) without careful stimulus construction"
  convergence:
    supporting_frameworks: [PREDICTIVE_PROCESSING]
    effective_independence: 1.0  # single framework
  novelty:
    tested: "partially — Joye & van den Berg (2011) tested fractal dimension"
    remaining_untested: "full 1/f spectral match without fractal structure"
  testability:
    design: "between-subjects: natural scene vs artificial 1/f scene vs scrambled control"
    measures: "salivary cortisol (pre/post), self-report affect, EEG alpha"
    sample_size_estimate: "~80 per group for d=0.4 at power=0.80"
    feasibility: "HIGH — stimuli can be generated computationally"
  theoretical_leverage: "MEDIUM — confirms PP mechanism but doesn't discriminate from biophilia (biophilia would predict natural > artificial even with matched spectra)"
```

### Step 5: Cross-Framework Convergence Assessment
*(Thagard, 1989, 1992; Gentner & Markman, 1997; incorporating R14)*

**Input**: All predictions from Step 4 across all mechanism traces.
**Operation**: Identify predictions supported by multiple framework traces. Compute effective independence. Flag contradictory predictions.
**Output**: Convergence-scored predictions; contradiction reports.

**Changes from V1.0**:
- Independence matrix is computed **per-prediction** (R14), not per-framework-pair. For each prediction, the system asks: "For THIS specific prediction domain, how much theoretical overlap do the supporting frameworks share?" This replaces the fixed 8×8 matrix with a dynamic computation.
- Independence computation considers: shared theoretical commitments relevant to this prediction, shared neural substrates relevant to this prediction, shared key assumptions relevant to this prediction.

### Step 6: Composition Failure Detection ← NEW STEP (R10)
*(Barrett's recommendation; connects to Kuhn's anomaly accumulation)*

**Input**: All attempted mechanism trace compositions from Step 3.
**Operation**: Identify cases where templates from different frameworks CANNOT be composed because they make incompatible assumptions about the same variable. Characterize the incompatibility. Generate discriminating predictions.
**Output**: Composition failure reports with discriminating predictions flagged as high-priority.

**Failure types**:
| Failure Type | Description | Example | Output |
|---|---|---|---|
| **Definitional conflict** | Frameworks define the same term differently | "Arousal" in neuromodulatory (autonomic activation) vs. dual-process (resource allocation) — different operationalizations lead to different predictions | Discriminating prediction that distinguishes the operationalizations |
| **Mechanistic conflict** | Frameworks posit incompatible mechanisms for the same phenomenon | Basic emotion theory (dedicated fear circuit) vs. constructionist theory (domain-general prediction + interoception constructs fear) | Discriminating prediction: does fear require amygdala? Constructionism says no for all types |
| **Scope conflict** | Frameworks agree on mechanism but disagree on scope | PP says complexity-preference is universal (prediction error optimization is universal). Embodied cognition says it's body-dependent (different bodies, different affordances, different preferences) | Cross-cultural/cross-population test of complexity preferences |
| **Parameter conflict** | Same mechanism, different predicted parameters | Two frameworks predict cortisol reduction from nature but disagree on timecourse (PP predicts fast onset via perceptual efficiency; allostasis predicts slow onset via anticipatory regulation) | Temporal resolution study measuring cortisol at multiple timepoints |

### Step 7: Prediction Prioritization
*(Popper, 1963; VOI framework; incorporating R5)*

**Input**: All predictions (from Step 4) + convergence scores (from Step 5) + composition failure discriminators (from Step 6) + alignable differences (R5).
**Operation**: Rank by: convergence score, derivation chain strength (weakest link maturity), novelty, testability, theoretical leverage (Popperian discriminating power), practical import.
**Output**: Prioritized prediction queue.

**Changes from V1.0**:
- Alignable differences from partial template matches (R5) are included as a category of predictions — "variables hypothesized to be present but unmeasured."
- Composition failure discriminators (from Step 6) receive automatic priority boost — they're where theoretical progress is most likely.
- Predictions with cross-framework convergence from genuinely independent frameworks receive priority boost proportional to effective independence.

### Step 8: Template Learning ← NEW STEP (R17, from Langley)

**Input**: Confirmed predictions from empirical testing.
**Operation**: When a prediction generated by composing two templates is empirically confirmed, consolidate the composition into a new template. When a prediction is disconfirmed, flag the weakest link for revision.
**Output**: New templates added to library; existing templates revised or deprecated.

**Learning rules**:
1. **Composition consolidation**: If templates A and B were composed to generate prediction P, and P is confirmed, create template AB that encodes the composed pathway. AB inherits scope conditions from both A and B.
2. **Link strengthening**: If a prediction was generated from a how-plausibly link and is confirmed, upgrade that link toward how-actually (with appropriate caution — single confirmation doesn't establish how-actually status).
3. **Link weakening**: If a prediction derived from a how-actually link is disconfirmed, investigate: was the prediction derived correctly? Was the test adequate? If yes to both, downgrade the link toward how-plausibly and flag for further investigation.
4. **Framework health update**: Track prediction success/failure rates per framework. Sustained failure rate above threshold → flag framework for revision consideration (R15/Gopnik).

## 2.3 Data Structures

### The Mechanistic Template
```yaml
template:
  # Identity
  id: string                          # e.g., "PP_SPECTRAL_MATCH_001"
  name: string                        # human-readable
  version: semver                     # for template learning updates

  # Source
  source_framework: FrameworkID       # primary Tier 1 framework
  secondary_frameworks: [FrameworkID] # cross-framework templates list multiple
  derivation_quality: HIGH|MEDIUM|LOW # how directly it follows from framework principles

  # Structural Level (R4 — for retrieval)
  structural_pattern: string          # e.g., "stimulus_efficiency → processing_cost_reduction → downstream_benefit"
  higher_order_principle: string      # e.g., "metabolic optimization"
  transferable_to: [domain_list]      # which sensory/cognitive domains this pattern applies to

  # Surface Level (R4 — for instantiation)
  entities: [EntitySpec]              # specific entities with types and measurability
  causal_chain: [LinkSpec]            # ordered sequence of causal links (see link structure above)

  # Quality
  overall_maturity: how-possibly|how-plausibly|how-actually   # R1: minimum across chain
  weakest_link_id: string             # which link is the bottleneck

  # Scope
  scope_conditions: ScopeSpec         # requirements, limitations, uncertain domains
  known_interactions: [InteractionSpec]  # R3: known interference patterns with other templates

  # Level information (R9)
  primary_level: ecological|computational|circuit|cellular|molecular
  levels_spanned: [level_list]        # which levels the template crosses
  cross_level_bridges: [BridgeSpec]   # explicit bridge descriptions with quality grades

  # Metadata
  key_references: [Citation]
  prediction_track_record:            # R17: updated by template learning
    predictions_generated: int
    confirmed: int
    disconfirmed: int
    untested: int
```

### The Framework Node (Revised — R15: Dynamic)
```yaml
framework:
  id: FrameworkID
  name: string
  status: ACTIVE|CANDIDATE|DEPRECATED    # R15: dynamic framework management
  tier: 1|2                              # Tier 1 = foundational; Tier 2 = domain-specific

  # Content
  core_principles: [Proposition]          # defining commitments
  neural_implementation_claims: [Proposition]
  scope_declaration: ScopeSpec            # R13: what it covers, what it doesn't

  # Known Issues
  known_problems: [ProblemSpec]           # dark room problem, unfalsifiability concerns, etc.
  contested_aspects: [ContestationSpec]   # what's debated within the field

  # Performance (R17/R19)
  health_metrics:
    template_count: int
    predictions_generated: int
    prediction_success_rate: float
    anomaly_count: int
    last_updated: datetime

  # Independence (R14 — structural information for per-prediction computation)
  shared_theoretical_commitments: {FrameworkID: [commitment_list]}
  shared_neural_substrates: {FrameworkID: [substrate_list]}
  shared_assumptions: {FrameworkID: [assumption_list]}
```

## Design Principles

Following the panel's recommendations:
- Start with 20 templates (Langley: iterate before expanding)
- Prioritize how-actually confirmed pathways (Darden: highest maturity first)
- Include cross-framework bridging templates (Craver: explicit level bridges)
- Include at least one allostatic pathway (Barrett: anticipatory regulation)
- Include domain-general structural templates (Gentner: transferable schemas)
- Cover all 8 Tier 1 frameworks
- Cover major outcome categories (Langley: cognitive, affective, behavioral, physiological)

## TEMPLATE 1: PP_SPECTRAL_MATCH_001
**"Visual scene statistics → prediction error reduction"**

**Structural pattern**: stimulus_efficiency → processing_cost_reduction
**Higher-order principle**: Metabolic optimization — the visual system processes evolutionarily familiar statistics more efficiently
**Transferable to**: Auditory (1/f temporal spectra in natural soundscapes), possibly olfactory (familiar scent profiles)

**Causal chain**:
1. Visual stimulus with specific spatial frequency spectrum → V1 efficient coding response
   - Level: ecological → circuit bridge
   - Bridging quality: HIGH
   - Maturity: **how-actually** (Olshausen & Field, 1996; Rao & Ballard, 1999; Simoncelli & Olshausen, 2001)
   - Evidence: Natural images have 1/f amplitude spectra; V1 neurons are optimally tuned to these statistics; coding efficiency is measurable via neural metabolic markers
2. Efficient coding → reduced prediction error magnitude in visual hierarchy
   - Level: circuit → computational bridge
   - Bridging quality: HIGH
   - Maturity: **how-actually** (Rao & Ballard, 1999; Bastos et al., 2012)
   - Parameter range: 40-60% reduction in prediction error for natural vs phase-scrambled scenes (estimated from fMRI BOLD)
3. Reduced prediction error → reduced cortical metabolic demand
   - Level: computational → cellular bridge
   - Bridging quality: MEDIUM
   - Maturity: **how-plausibly** (theoretical derivation from efficient coding; direct metabolic measurements are sparse)
   - Parameter range: Estimated 10-20% reduction in glucose utilization in early visual cortex (extrapolated from Laughlin, 2001)

**Scope conditions**: Requires intact early visual processing; applies to scenes viewed for >200ms; uncertain for very low contrast or peripheral stimulation.
**Known interactions**: Top-down attention can override efficient coding advantages; adaptation over minutes reduces the advantage.
**Overall maturity**: **how-plausibly** (limited by link 3)

**Key references**: Olshausen & Field (1996, cited ~6,000); Rao & Ballard (1999, cited ~5,000); Simoncelli & Olshausen (2001, cited ~3,500); Laughlin (2001, cited ~800); Bastos et al. (2012, cited ~2,500)

## TEMPLATE 2: PP_COMPLEXITY_GOLDILOCKS_002
**"Stimulus complexity → inverted-U hedonic response"**

**Structural pattern**: stimulus_dimension → optimization_zone → hedonic_evaluation
**Higher-order principle**: Goldilocks optimization — moderate prediction error (resolvable challenge) is rewarding; too little is boring; too much is aversive. This is a DOMAIN-GENERAL schema (Gentner's recommendation).
**Transferable to**: Visual complexity, auditory complexity, spatial complexity, social density, information density, thermal variation, olfactory complexity

**Causal chain**:
1. Stimulus complexity (on any dimension) → prediction error magnitude
   - Level: ecological → computational
   - Bridging quality: HIGH (across modalities)
   - Maturity: **how-actually** (Berlyne, 1971; Schmidhuber, 2010; Van de Cruys, 2017)
2. Prediction error magnitude → precision-weighting demand → metabolic cost
   - Level: computational → cellular
   - Bridging quality: MEDIUM

   - Level: ecological → circuit
   - Bridging quality: HIGH
   - Maturity: **how-actually** (Lisman & Grace, 2005)
2. Hippocampal novelty signal → VTA dopamine release → mesolimbic activation (nucleus accumbens)
   - Level: circuit
   - Bridging quality: HIGH
   - Maturity: **how-actually** (Bunzeck & Düzel, 2006)
3. Mesolimbic dopamine → "wanting" (incentive salience) → approach behavior and exploration
   - Level: circuit → psychological → behavioral
   - Bridging quality: MEDIUM
   - Maturity: **how-actually** for wanting/approach (Berridge & Robinson, 2016); **how-plausibly** for the distinction between wanting (dopaminergic) and liking (opioidergic) in architectural contexts

**NOTE**: Wanting ≠ liking. Novel architecture may produce strong approach behavior (wanting to explore) without necessarily producing hedonic pleasure (liking the space). This dissociation is predicted by Berridge's incentive salience theory and is testable.

**Scope conditions**: Novelty response habituates with repeated exposure (~3-5 exposures). The response is modulated by arousal state (low arousal → stronger novelty seeking; already-aroused → reduced novelty seeking). Connects to NM_NORADRENERGIC_EXPLORE_006 — LC-NE state modulates the threshold for novelty-driven exploration.
**Overall maturity**: **how-actually** for the neural pathway; **how-plausibly** for specific architectural applications

**Key references**: Lisman & Grace (2005, cited ~2,000); Bunzeck & Düzel (2006, cited ~1,000); Berridge & Robinson (2016, cited ~1,500)

## TEMPLATE 18: EC_VESTIBULAR_SPATIAL_COGNITION_001
**"Architectural vertical dimension → vestibular processing → cognitive style"**

**Structural pattern**: spatial_feature → sensory_system_engagement → cognitive_modulation

**Causal chain**:
1. Vertical architectural features (high ceilings, multi-story atria, vertical views, staircases) → vestibular system engagement via vertical gaze shifts, head tilting, and vertical locomotion
   - Level: ecological → circuit
   - Bridging quality: MEDIUM
   - Maturity: **how-plausibly** (Hitier et al., 2014 — vestibular contributions to spatial cognition; specific architectural applications are newer)
2. Vestibular processing → hippocampal-parietal integration → spatial reference frame modulation
   - Level: circuit
   - Bridging quality: MEDIUM
   - Maturity: **how-plausibly** (Brandt et al., 2005; Smith, 1997)
3. Spatial reference frame → cognitive processing style (more expansive/abstract vs. more constrained/concrete)
   - Level: circuit → psychological
   - Bridging quality: LOW
   - Maturity: **how-possibly** (Meyers-Levy & Zhu, 2007 showed ceiling height affects processing style; vestibular mediation is a proposed but untested mechanism)

**Scope conditions**: Requires physical presence (not images); requires functional vestibular system; effects may be modulated by experience (e.g., people accustomed to low-ceiling environments may process differently).
**Overall maturity**: **how-possibly** — this is a speculative but well-motivated template

**Key references**: Hitier et al. (2014, cited ~300); Meyers-Levy & Zhu (2007, cited ~1,000)

## TEMPLATE 19: XF_SOCIAL_AFFORDANCE_DENSITY_001
**"Spatial layout → social affordances → social behavior patterns"**

**Structural pattern**: environmental_structure → perceived_interaction_possibilities → behavioral_regulation

**Causal chain**:
1. Spatial layout features (seating arrangements, path widths, visual connections between zones, acoustic properties, proxemic distances) → perceived social affordances (opportunities for interaction, privacy regulation, personal space control)
   - Level: ecological → computational
   - Bridging quality: MEDIUM
   - Maturity: **how-plausibly** (Hall, 1966; Altman, 1975; extensive environmental psychology literature)
2. Social affordances → behavioral regulation of social interaction (approach/avoid, group formation, conversation patterns, dwelling behavior)
   - Level: computational → behavioral
   - Bridging quality: HIGH (strong observational evidence)
   - Maturity: **how-actually** for basic effects (decades of environmental psychology research)
3. Social behavior patterns → interoceptive/affective consequences → wellbeing effects
   - Level: behavioral → systems → psychological
   - Bridging quality: MEDIUM
   - Maturity: **how-plausibly**

**Moderators**: Cultural proxemic norms (Hall, 1966 — contact vs. non-contact cultures), introversion/extraversion (optimal social density differs), task demands (collaboration vs. focused work require different layouts), social relationships (strangers vs. colleagues vs. intimates).
**Scope conditions**: Physical copresence required — this template does not apply to virtual interaction. Density effects are nonlinear: very low density can be as aversive as very high density (isolation vs. crowding — another Goldilocks pattern).
**Overall maturity**: **how-plausibly** — the behavioral regularities are well-established but mechanistic mediation is less specified than other templates

**Key references**: Hall (1966, cited ~10,000); Altman (1975, cited ~5,000)

## TEMPLATE 20: XF_ENVIRONMENT_COGNITIVE_PERFORMANCE_001
**"Environmental features → cognitive resource modulation → task performance"**

**Structural pattern**: environmental_conditions → resource_availability → performance_outcome

This is a higher-order composed template integrating multiple pathways:

**Resource depletion pathways** (reduce available cognitive resources):
- Noise → auditory prediction error → attentional capture → working memory depletion (PP + DP)
- Thermal discomfort → interoceptive prediction error → regulatory demand → reduced executive function (IC + NM)
- Navigation difficulty → spatial processing demand → reduced capacity for other tasks (SN + DP)
- Threat cues → vigilance demand → attentional narrowing (NM + DP)

**Resource enhancement pathways** (increase available cognitive resources):
- Natural elements → PP_SPECTRAL_MATCH_001 → reduced processing cost → freed resources
- Good spatial layout → SN_LAYOUT_COGNITIVE_MAP_001 → reduced navigation demand → freed resources
- Thermal/acoustic comfort → low interoceptive prediction error → freed regulatory resources
- Safety cues → reduced vigilance demand → freed attentional resources

**Net cognitive performance** = baseline capacity - sum(depletion pathways) + sum(enhancement pathways)

**Key prediction**: Environmental effects on cognitive performance should be DECOMPOSABLE into specific pathway contributions. An office that is noisy but well-lit and well-laid-out should show specific deficits (working memory, per noise pathway) but preserved spatial cognition (per layout pathway). This decompositional prediction is different from the global "good environments help, bad environments hurt" claim — it predicts SPECIFIC patterns of performance effects from specific environmental feature combinations.

**Overall maturity**: **how-plausibly** — individual pathways vary; the compositional model is how-possibly
