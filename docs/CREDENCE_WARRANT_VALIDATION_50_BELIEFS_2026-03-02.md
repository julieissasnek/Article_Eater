## Methodology Notes

### Design Type Inference

Design types were inferred from extraction metadata and finding statistics using the following heuristic:
1. Meta-analysis/systematic review signals in title → META_ANALYSIS or SYSTEMATIC_REVIEW
2. Theoretical propositions → WITHIN_SUBJECTS (conservative)
3. RCT signals + N > 200 → LARGE_RCT
4. RCT signals or p_value present → STANDARD_RCT
5. Effect size or sample size without p_value → OBSERVATIONAL
6. Default → OBSERVATIONAL

### Old Credence Formula

base = ae_confidence × p_value_adjustment
- p_value ≤ 0.01: adjustment = 1.0
- p_value ≤ 0.05: adjustment = 0.9
- p_value > 0.05: adjustment = 0.7
- no p_value: adjustment = 0.5

### New Credence Formula

Warrant-derived credence computed from composite ω via logit projection:
credence = sigmoid(logit(ae_confidence) + sum(logit(warrant_i)) for all warrant components)
