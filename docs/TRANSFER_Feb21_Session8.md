# ⚠️ CRASH-RESILIENCE PROTOCOL — READ FIRST, APPLY ALWAYS

**Context**: Claude Opus crashes with high frequency during long panel runs. Loss of
work from a crash is unacceptable. The following protocol is MANDATORY for every
panel session without exception.

## The Protocol

**Before writing any panel content:**
1. Create the output file immediately — header block only — in `/home/claude/`.
2. Copy that stub to `/mnt/user-data/outputs/` right away.

**During panel production (every ~200–300 lines of content):**
3. Append the completed section to the file using `bash` → `cat >> file << 'DELIMITER'`.
4. Immediately copy the updated file to `/mnt/user-data/outputs/`.
5. Confirm the line count has grown (`wc -l`) before continuing.

**Never write the entire panel as a single heredoc.** The buffer overflow is what
causes crashes. Section-by-section appends avoid it entirely.

**The save cadence:**
- After Round Table opens: save
- After each opening statement: save (or at minimum after every 2)
- After each Crucible debate: save
- After each calibrated JSON block: save
- After each Output Block: save

**Recovery procedure after a crash:**
- The last saved file in `/mnt/user-data/outputs/` IS the fallback
- Do NOT restart from scratch — read the file, identify the last completed section,
  and resume from the next section
- Tell the user: "Resuming from [last section]. Continuing..." — do not re-debate
  sections that were already written and saved

This protocol applies to ALL long-form outputs, not just panels. Any file exceeding
~400 lines should be built incrementally with intermediate saves.

- **Dacher Keltner** (UC Berkeley) — the empirical authority on awe phenomenology,
  small-self, and the awe induction paradigm. His 2003 taxonomy and 2023 "Awe"
  monograph are the primary awe literature anchors.
- **Jonathan Haidt** (NYU Stern) — moral elevation and the awe-related self-
  transcendent emotions. Provides the positive-psychology framing of awe as
  distinct from fear (which is also a high-PE response).
- **Lars Muckli** (returns from VISUAL-I) — V1 dual-adaptation state during extreme
  luminance contrast; the neural mechanism for why awe has a distinct visual
  phenomenology (light visible as substance).
- **Julio Bermudez** (Catholic University, Catholic University of America) — the only
  researcher with direct fMRI data from architecturally-induced extraordinary
  aesthetic experiences (EAE). His data on Gothic cathedral vs. control building fMRI
  comparisons are the highest-quality direct architectural awe data available.
- **Moshe Bar** (returns from VISUAL-I) — the categorical prediction failure that
  occurs when a space exceeds the generative model's schema capacity is Bar's
  'accommodation demand' translated into PP terms.
- **Roger Ulrich** (returns) — to provide the SRT boundary condition: when does
  high-arousal awe cross from restorative (parasympathetic) to stressful
  (sympathetic)?
