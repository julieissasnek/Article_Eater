## Running Future Scans

### Daily Incremental
```bash
python3 /tmp/run_scanner.py
# Reports new/modified files since last scan
# Runtime: 2-5 seconds
# State file: automatically updated
```

### Weekly Full Audit
```bash
python3 /tmp/run_scanner.py --full-audit
# Re-scans entire docs/ and src/ trees
# Runtime: ~30 seconds
# Creates new SYNC_REPORT_YYYY-MM-DD.md
```

### Manual Catch-up
```bash
python3 /tmp/run_scanner.py --since 2026-02-24
# Find files modified after given date
# Runtime: 5-10 seconds
```

See DOC_SYNC_SCANNER_QUICKREF.md for detailed instructions and troubleshooting.
