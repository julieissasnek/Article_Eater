## Purpose

Doc 66 Stress Test 4 found that PE does real explanatory work in ~30-40% of templates and provides organizational vocabulary in the rest. This addendum classifies every template so the system is honest about what PE contributes.

## Classification Key

- **predictive**: PE framework generates a quantitative prediction that differs from what the empirical literature alone provides. The PE mechanism IS the explanation.
- **explanatory**: PE framework explains known empirical findings mechanistically. The findings were discovered without PE, but PE provides the WHY. Removes PE → loses the mechanistic story but keeps the parameters.
- **organizational**: PE provides consistent vocabulary and a place in the taxonomy. Removes PE → the template still works as an empirical parameterization.
