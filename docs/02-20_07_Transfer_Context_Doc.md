## Key Theoretical Points Developed This Session

### 1. Activity Space as Tier 1 Framework
- Only framework operating at logical level (goal-subgoal structure)
- Structurally complementary to all other Tier 1 theories (PP, Berlyne, ART, Biophilia, SRT)
- Templates are uniquely *moderating* — predict boundary conditions for other template application
- Four proposed templates: T_AS_001 (Cognitive Congeniality Modulation), T_AS_002 (Epistemic Bubble Gating), T_AS_003 (Multi-Activity Interference), T_AS_004 (Cognitive Congeniality as Distinct from Physical Optimization)

### 2. Explicit Processing Advantage (slides 25-28)
- Kidd & Hayden inverted-U is infant/animal — can't generalize to adult explicit processing
- Adults override implicit inverted-U, operate at higher abstraction
- Two channels: implicit (autonomic, PE) + explicit (aesthetic judgment, semantic meaning, cultural norms)
- Goldilocks uniquely normative → can integrate both channels

### 3. Activity Space ↔ Implicit/Explicit Bridge (NEW — V6)
- Activity frame is partly explicit (deliberate goal selection)
- Once set, it reconfigures affordance ecology → alters what implicit system processes
- Epistemic bubble gates which physical features generate PE
- Same physical stimulus → different PE profiles depending on activity
- Connects to inattentional blindness (Simons & Chabris 1999)

### 4. Cognitive Niche Engineering
- Extended mind thesis (Clark & Chalmers 1998) → design IS cognitive niche engineering
- Niche must be tuned to activities occupants pursue (Kirsh, 2026)
- Feedback loop: culture → niche → preferences → niche reconstruction
- Varanasi as cognitive niche in dynamic equilibrium
