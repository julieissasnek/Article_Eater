## Design Principles Applied

All figures adhere to the following standards:

1. **Tufte's Data-Ink Ratio**: Maximized data representation, minimized decorative chartjunk
   - No 3D effects, gradients, or unnecessary gridlines
   - Direct labeling preferred over legends where feasible
   - Clean, minimal color schemes

2. **Perceptual Hierarchy** (Cleveland & McGill):
   - Position encoding used first (most salient)
   - Length and area for comparisons
   - Color for categorical distinctions only

3. **Colorblind-Safe Palettes**: All figures use palettes verified for deuteranopia and protanopia
   - Viridis-inspired primary colors (#1f77b4, #ff7f0e, #2ca02c)
   - Luminance variation for accessibility
   - No red-only or red-green-only distinctions

4. **Typography**:
   - Sans-serif fonts (DejaVu fallback for Helvetica/Arial)
   - Readable at journal column width (~3.3 inches)
   - Clear mathematical notation with proper symbols

5. **Scientific Captions**: Each figure includes a 3-6 sentence caption that:
   - States what the figure shows
   - Explains the key finding
   - Notes implications for theory or practice
   - Is self-contained and readable without full text
