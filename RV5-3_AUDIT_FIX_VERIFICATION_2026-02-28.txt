AUDIT ISSUE DEFINITION
================================================================================

Title: Direction field has 169 unique values but should have exactly 4
       canonical values

Severity: CRITICAL
Category: Data Quality / Schema Compliance

Description:
  The "direction" field in finding records should contain only 4 canonical
  values representing the type of relationship/effect:
    - increase    (positive/enhancing effects)
    - decrease    (negative/reducing effects)
    - no_effect   (null/non-significant effects)
    - mixed       (complex/conditional/bidirectional effects)

  However, analysis found 1,723+ unique direction values ranging from
  proper semantic variations (e.g., "increased", "decreases") to
  completely wrong values (e.g., claim_type terms like "causal",
  "associational" leaked into the direction field).

Impact:
  - Data quality violation: Non-compliant schema
  - Filtering/analysis impossible: Cannot group by standardized direction
  - Pipeline integrity: Downstream processing expects canonical values
  - Audit compliance: RV5-3 finding must be resolved

Recommendation:
  Update extraction templates and prompts to:
  1. Explicitly define direction values (increase/decrease/no_effect/mixed)
  2. Explicitly define claim_type values (causal/associational/etc.)
  3. Enforce separation between the two fields
  4. Add validation in extraction pipeline to prevent future leaks
