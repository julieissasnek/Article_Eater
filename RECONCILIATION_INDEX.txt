USING THE RESULTS
================================================================================

STEP 1: Extract Matches
  Read reconciliation_results.json
  For each item in "resolved_by_content_match":
    - template_id: which template
    - requested_step: decision was for this step
    - matched_step: but actually matched to this step
    - match_score: confidence (0.30-0.84 range)
    - template_file: where to apply
    - confidence: decision confidence value
    - warrant: warrant type (MECHANISM, etc.)

STEP 2: Apply Successful Matches
  For high-confidence matches (score > 0.70):
    - Apply directly, include match_score in audit trail
  For medium-confidence matches (0.50-0.70):
    - Apply with review flag, note match_score
  For low-confidence matches (0.30-0.50):
    - Flag for expert review before applying

STEP 3: Handle Unresolvable
  For each item in "unresolvable":
    - Check reason: "No content match" or "No mechanism chain"
    - If "No mechanism chain":
      → Template file needs implementation
    - If "No content match":
      → Either template needs step_number field
      → OR decision step numbers need validation
    - Follow Priority recommendations below

STEP 4: Track Progress
  Re-run script as templates are fixed:
    - Re-run: python3 scripts/reconcile_step_mismatches.py
    - Compare: new unresolvable count vs. old
    - Target: Get unresolvable count to 0 or <10
