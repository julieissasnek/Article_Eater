ENVIRONMENT VARIABLES
=====================

AE_QA_INTEGRATION
  Default: "true"
  Purpose: Master switch for all QA integration
  Effect: If "false", returns "disabled" status

AE_CONFOUNDER_CHECKER
  Default: "true"
  Purpose: Enable/disable confounder risk assessment
  Effect: If "false", skips confounder assessment step

AE_CREDENCE_INTERVALS
  Default: "true"
  Purpose: Enable/disable credence interval computation
  Effect: If "false", skips credence assessment step

Usage:
  export AE_CONFOUNDER_CHECKER=false
  python scripts/scheduled_pipeline.py run --stage qa_confounder

ERROR HANDLING PATTERNS
=======================

Pattern 1: Import Errors
  try:
      from src.qa.confounder_risk_checker import ConfounderRiskChecker
      checker = ConfounderRiskChecker()
      ...
  except ImportError as e:
      logger.warning(f"ConfounderRiskChecker not available: {e}")
      return {"status": "unavailable", "error": str(e)}

Pattern 2: Non-Fatal Failure
  try:
      result = _run_confounder_assessment(beliefs)
  except Exception as e:
      logger.warning(f"Confounder assessment failed (non-fatal): {e}")
      result = {"status": "error", "error": str(e)}
  # Continue with next assessment

Pattern 3: Pipeline Non-Blocking
  result = batch_assess_findings()
  if result.get("status") == "error":
      log.warning(f"QA batch assessment failed: {result.get('error')}")
      return True  # Non-fatal — don't block pipeline!
