================================================================================
METHODOLOGICAL APPROACH
================================================================================

Kirsh's Decision Tree Method:

Step 1: Filter Environmental Stimuli
  - Remove non-environmental: demographics, drugs, brain stimulation
  - Keep: architectural features, lighting, materials, plants, etc.
  - Result: 16,948 environmental stimuli

Step 2: Cluster into Commonsense Categories
  - Extract environmental keywords from stimulus descriptions
  - Hierarchical semantic rules assign to primary category
  - Result: 53 clusters, top 25 analyzed

Step 3: Apply Decision Tree Analysis
  For each category, systematically vary attributes:
    - Plant presence (present/absent) → ESSENTIAL
    - Plant species (varied) → INCIDENTAL
    - Pot material (varied) → INCIDENTAL
    - Lighting context (varied) → INCIDENTAL
  
  Result: Essential attributes define equivalence class

Step 4: Map to Scientific Attributes
  - Identify which of 21 existing attributes apply
  - Discover gaps → new attributes needed
  
Step 5: Specify Vision Algorithms
  - All 12 new attributes have implementable algorithms
  - Three tiers: OpenCV-only, pretrained models, custom models
  - Complete pseudocode provided

EXAMPLE: ROOM WITH PLANTS
================================================================================

Decision Tree Variations:
  Plant presence (present/absent/artificial) → ESSENTIAL
  Plant species (succulent/fern/pothos) → INCIDENTAL
  Green chromaticity (vibrant/muted) → ESSENTIAL
  Plant size → INCIDENTAL
  Pot material → INCIDENTAL
  Lighting context → INCIDENTAL
  Room function → INCIDENTAL
  Biomorphic form (natural/pruned) → PARTIALLY ESSENTIAL

Essential Attributes:
  {plant_presence, green_chromaticity, biomorphic_form}

Equivalence Class Definition:
  "Any indoor or semi-outdoor space containing visible LIVING plants
   with GREEN foliage and recognizable BIOMORPHIC form"

Scientific Attributes Needed:
