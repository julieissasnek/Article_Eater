HOW CONTENT MATCHING WORKED
================================================================================

Strategy: Three-tier matching system

TIER 1: EXACT STEP NUMBER MATCHING
- For each decision with step N, search for a step with step_number=N
- Result: 10 exact matches found

TIER 2: CONTENT-BASED SEMANTIC MATCHING
- When exact match not found, score each step in the mechanism_chain
- Scoring factors:
  * Warrant type alignment (weight 0.40)
    - Direct match in step description
    - MECHANISM/EMPIRICAL_COVARIANCE keyword matching
  * Confidence proximity (weight 0.30)
    - Difference < 0.1: full score (0.30)
    - Difference < 0.2: partial score (0.15)
  * Rationale keyword matching (weight 0.30)
    - Key terms: "replicability", "biological plausibility",
      "multiple pathways", "well-supported", "consistent"
    - Each match += (1/5) * 0.30
- Acceptance threshold: score > 0.30
- Result: 96 content-based matches found

TIER 3: UNRESOLVABLE CASE IDENTIFICATION
- When no match found, categorize the failure reason
- Document available vs. requested steps
- Flag for manual intervention

================================================================================
ROOT CAUSE ANALYSIS
================================================================================

1. TEMPLATE VERSIONING MISMATCH
   - Ceiling decisions were made against template concept IDs
   - But actual resolved templates have different step counts/names
   - Example: Assumed COLLABORATIVE_CREATIVITY had 7 steps, but only has 3

2. MISSING STEP IDENTIFIERS
   - Many templates don't populate step_number field
   - Prevents direct matching and makes content matching weaker
   - Affects ~40% of unresolvable decisions

3. INCOMPLETE TEMPLATE SET
   - 5-8 template files appear to be stubs (AX9, COL1, M4, M9, NM2, TP4, etc.)
   - Have 0 steps or minimal data
   - Included in fuzzy matching resolution but unusable

4. CONCEPT DRIFT
   - Fuzzy template matching created synthetic IDs (CB_SLEEP_ARCHITECTURE_002)
   - Original panel didn't know actual step structure
   - Decisions were made abstractly, not against actual templates
